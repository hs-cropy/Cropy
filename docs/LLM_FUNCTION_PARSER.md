\# LLM 기능 토큰 파서



\## 목적



LLM이 반환한 단일 기능 토큰 문자열을 함수명과 인자로 변환한다.

함수를 실행하거나 누락된 인자를 추측하지 않는다.



\## 입력 형식



기능 토큰 → 정의된 순서의 인자 토큰 → <hs-end>



예:

<hs\_get\_pesticide\_information><hs\_topic\_reentry><hs\_product\_current><hs-end>



7개 기능과 기능별 허용 인자를 검사한다.

앞뒤 공백은 허용하지만 토큰 사이 공백, 자연어·JSON·코드 블록,

알 수 없는 기능·인자, 인자 순서 오류, 여러 기능 호출,

종료 토큰 누락 및 512자를 초과하는 입력은 거부한다.



잘못된 입력은 InvalidFunctionOutput 예외를 발생시킨다.

호출 측의 템플릿 대체 처리와 handler 연결은 후속 작업이다.



\## 검증



Windows 로컬에서 확인했다.



\- 파서 테스트: 33 passed

\- v11\_사람검수\_대조용정답.csv: 131건 모두 함수명·인자 일치

\- 전체 백엔드 테스트: 486 passed, 24 skipped, 1 warning



CSV 대조는 참조 정답의 토큰 형식 호환성을 확인한 것이다.

전체 학습 데이터 검수, 사용자 의도에 대한 정답 정확도,

실제 모델의 토큰 ID·종료 처리, handler 실행 및 보드 검증을

의미하지 않는다.



기존 generate\_guidance 및 공개 API의 동작은 변경하지 않는다.
