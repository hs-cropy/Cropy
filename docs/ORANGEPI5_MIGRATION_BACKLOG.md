# Orange Pi 5 Plus 역할별 이전 백로그

> 갱신: 2026-09-17. 대상: Orange Pi 5 Plus / RK3588 / RAM 16GB.
> 기본 구성: CNN CPU 기준선 검증 → Qwen/RKLLM NPU 실행 → 음성 통합 → 측정에 따른 최적화.
> 보드 이전의 우선순위·담당·완료 조건은 이 문서를 기준으로 한다. 학기 일정의 S1~S4 ID는 유지하며 중복 작업은 같은 완료 증거를 참조한다.
> 상태는 모두 미검증 계획이다. 실제 결과를 Issue에 기록하기 전 완료로 처리하지 않는다.

## 1. 역할

| 약어 | 담당 | 책임 |
|---|---|---|
| ML | 김헌영 | 모델·데이터·입출력 규격·정확도·LLM 평가 |

## 5. 게이트와 추적

- 보드 도착 주차와 무관하게 OP-03~06을 즉시 착수한다. 기존 10주차 배포·12주차 측정은 최초 검증을 미루는 조건이 아니다.
- 패키지 미수령 중에는 데이터·계약·CPU 배포를 진행한다. 변환 검증 전 대규모 LLM 학습을 시작하지 않는다.
- 보드 미수령 시 PC 결과와 보드 미검증 항목을 분리한다.
- ONNX INT8은 RKNN의 필수 선행 산출물이 아니다. RKNN 경로는 변환기가 요구하는 원본 ONNX와 이미지 캘리브레이션으로 별도 검증한다.
- Issue에는 상태(대기/진행/검증/완료), 선행 OP ID, 주담당, 산출물, 검증 환경·결과를 기록한다.
- 학기 일정 매핑: S1-04/05→OP-02, S1-14/S2-03/04/S3-11→OP-17~19, S2-05→OP-06, S3-07→OP-13, S3-10/12→OP-01/03/04/11, S4-02/03→OP-14, S4-05/06→OP-16/21.
