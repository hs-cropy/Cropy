# Cropy 음성 통합과 SUDA 대안 검토

**갱신:** 2026-10-08 · **상태:** 음성 통합 계획, SUDA 지원 미확정

## 1. 현재 우선 경로

목표 단말은 Orange Pi 5 Plus/RK3588/RAM 16GB다. 현재 Cropy에는 CNN·FastAPI·SQLite·웹앱이 있으며 음성·Qwen·SUDA는 연결되어 있지 않다.

우선은 CNN CPU 기준선 → 제공 RKLLM 패키지와 Qwen 기본 모델 검증 → 오프라인 STT/TTS → 전체 통합·실측이다. SUDA는 SDK·지원 하드웨어·기능 호출·한국어 처리·제공 조건을 확인한 뒤 비교한다. 다른 칩의 소개 사례나 응답 속도를 Cropy 보드 실측으로 쓰지 않는다.

## 2. 목표 사용자 시나리오

| 시나리오 | 필요한 연결 | 현재 상태 |
|---|---|---|
| 촬영→진단→결과 낭독 | 카메라·CNN·진단 API·TTS | 사진 업로드 진단은 구현, 단말 촬영·음성 미구현 |
| 판별부위 재촬영 안내 | recapture 지침·카메라·refine·TTS | 웹 재촬영 구현, 음성 미구현 |
| 병해·농약 정보 질문 | 질문 의도·현재 진단 근거·handler·TTS | 기능 데이터 초안, handler 미검증 |
| 진단 이력 조회 | 대상 확인·history·요약 낭독 | REST 이력 구현, 음성 조회 미구현 |
| 모호함·지원 범위·STT 오류 | 확인 질문·범위 안내·재시도 | 데이터 검수 단계 |

방제 일지·실제 살포 횟수·농장별 이력·인큐박스 음성은 후속 범위다. 현재 진단 이력으로 실제 농약 사용 횟수를 판단하지 않는다.

## 3. 근거를 유지하는 응답

```text
카메라/파일 → CNN → FastAPI/병해·농약 DB → 현재 진단 근거
마이크 → STT → 질문/근거 → Qwen 기능 선택 → 허용 handler
                                               ↓
                                  근거 검증·템플릿 → 화면/TTS
```

이 흐름의 STT·Qwen·handler·TTS는 목표 구조다. 실제 SUDA의 출력·도구 호출 방식이 다르면 별도 adapter 계약을 정의한다.

- confidence는 모델 분류 점수이고 확진 또는 실제 발병 확률로 설명하지 않는다.
- severity는 DB의 병해 속성이고 사진의 진행 정도로 설명하지 않는다.
- 병명·후보·recapture 조건과 안내는 백엔드 근거를 유지한다.
- 농약명·희석비·PHI·사용 조건은 검증된 작물·병해별 데이터에서만 가져온다. null·미검증이면 정보 부족을 안내한다.
- 수치를 계산할 경우 별도 검증 코드와 필수 입력을 정의한다. 이번 계획을 근거로 실제 사용량을 안내하지 않는다.
- 근거 검증 전에 숫자 문장을 낭독하지 않는다. 모델/시연 출처를 구분하고 실패 시 기존 진단과 검증된 템플릿을 유지한다.

## 4. 데이터·평가 상태

7기능 싱글턴 2,800개(train 2,240/validation 560) 초안이 있다. v6 AI 검수는 문제 미발견 2,239/보류 397/불합격 164, 사람 승인 0개다. 실제 녹음·STT·tokenizer ID·학습·handler·TTS·보드 추론 검증은 별도다.

불합격·반환 경계를 수정하고 사람 검수를 거친 뒤 기능 선택·인자·종료와 근거 응답을 소량 시험한다. 음성 평가는 실제 잡음·병명·작물명·짧은 발화·권한 거부·자기 음성 재인식을 포함한다. 첫 토큰·전체 응답 시간·RAM·온도·전력은 같은 보드에서 기록한다.

근거: [LLM 계획](LLM_FINETUNING_PLAN.md), [v6 데이터 검수](../마음ai/Qwen35_데이터시트/전체2800_매뉴얼기반_AI검수_v6.md).

## 5. SUDA 채택 전 확인사항

RK3588 지원과 실제 CPU/NPU 실행, SDK 언어·배포 형태, 한국어·농업 어휘, tool/function 호출과 컨텍스트 주입, 마이크·웨이크워드 조건, 라이선스·제공 범위를 확인한다. 지원을 확인하지 않은 상태에서 완전 오프라인·응답 속도·비용 0원을 보장하지 않는다.

지원되는 경우 동일 질문과 근거로 Qwen/STT/TTS 경로와 비교한다. 효과·자원·통합 유지비가 나아지는지 확인한 뒤 선택한다. [단말 설계](DEVICE_HARDWARE.md)의 SUDA 도식은 초기 대안이며 실제 구현이 아니다.

## 6. 실행과 후속 작업

[배포 가이드](ORANGEPI5_DEPLOY.md)와 [이전 백로그](ORANGEPI5_MIGRATION_BACKLOG.md)의 OP-06~16을 따른다. 실제 스마트폰/보드 카메라·마이크, 신뢰된 HTTPS, 인터넷 차단·캐시 없는 최초 접속, 재부팅·데이터 보존과 전체 음성 흐름을 함께 검증한다.
