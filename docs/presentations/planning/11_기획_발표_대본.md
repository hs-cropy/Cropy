# 기획 발표 대본 (3~4분)

> 팀 소개 + 프로젝트 소개. 분량 약 900자, 말하는 속도 기준 3분 30초.
> 특허 출원 전이므로 재촬영 알고리즘의 세부 수치는 말하지 않는다.

---

## 0. 인사 (15초)

안녕하십니까. 크래파스 팀입니다. 저희는 인터넷이 없는 밭 한가운데서도 작물 병해를 진단하고 음성으로 방제 방법까지 알려주는 단말기, **Cropy**를 만들고 있습니다.

## 1. 팀 소개 (30초)

저희 팀은 다섯 명이고, 각자 하나의 개발 파트를 맡습니다.

- 김헌영, 팀장이자 PM으로 CNN 진단 모델을 담당합니다.
- 김민서, 프론트엔드 웹앱 화면을 담당합니다.
- 박성호, 백엔드 API와 데이터베이스를 담당합니다.
- 고명준, 카메라 촬영과 음성 인터페이스를 담당합니다.
- 이서하, 백엔드 배포와 오렌지파이 디바이스를 담당합니다.

발표와 문서는 매주 돌아가며 맡아 전원이 기록에 참여합니다.

## 2. 문제 (40초)

농작물 병해는 초기에 잡아야 피해를 막을 수 있습니다. 그런데 현장에는 세 가지 벽이 있습니다.

첫째, 산간 농지와 철골 비닐하우스는 통신이 끊기는 곳이 많아 클라우드 앱이 동작하지 않습니다.
둘째, 주 사용자가 고령 농업인이라 작은 글씨와 복잡한 터치 화면이 진입장벽입니다.
셋째, 농약은 희석 배수와 수확 전 사용금지일을 잘못 읽으면 곧바로 사고로 이어집니다.

기존 진단 앱은 이 세 가지를 해결하지 못했습니다.

## 3. 해결책 (60초)

CropCare AI는 **완전 오프라인 온디바이스 진단 단말**입니다.

카메라로 작물을 찍으면 단말 안의 CNN 모델이 고추, 무, 배추의 여섯 가지 병해와 정상 상태를 바로 판별합니다. 현재 모델은 테스트 정확도 93퍼센트에 도달했습니다.

진단 결과는 화면이 아니라 **음성**으로 전달됩니다. "탄저병일 확률이 높습니다, 병든 열매를 제거하고 등록 농약을 2천 배로 희석하세요"처럼 말로 안내하고, 농부가 되물으면 다시 설명합니다. 손에 흙이 묻어 있어도, 글씨가 안 보여도 쓸 수 있습니다.

비슷한 병해가 헷갈릴 때는 단말이 먼저 "잎을 뒤집어서 뒷면을 찍어주세요"라고 재촬영을 유도해 정확도를 높입니다. 이 부분은 저희 팀의 핵심 아이디어로 특허 출원을 준비 중입니다.

농약 정보는 농촌진흥청 등록농약 데이터베이스를 기반으로 제공해, 등록되지 않은 약을 추천하는 일이 없도록 합니다.

## 4. 기술 구성 (30초)

하드웨어는 오렌지파이 5에 카메라, 마이크, 스피커를 붙인 독립 단말입니다.
진단 모델은 ResNet50을 NPU용으로 양자화해 올리고, 음성은 마음AI의 온디바이스 대화 모델 SUDA를 연동하는 것을 목표로 합니다. SUDA 확보가 늦어질 경우를 대비해 오픈소스 음성 파이프라인도 병행 준비합니다.

## 5. 일정과 마무리 (30초)

14주 계획입니다. 보드가 도착하기 전까지는 스마트폰 브라우저 웹앱으로 촬영, 진단, 음성 안내를 먼저 완성해 7주차 중간발표에서 시연합니다. 후반부에는 이를 오렌지파이 단말로 옮기고 NPU 추론과 음성 대화를 붙여 14주차에 실제 단말로 시연하겠습니다.

인터넷 없는 밭에서, 말 한마디로 진단부터 방제까지. 크래파스 팀의 CropCare AI였습니다. 감사합니다.

## 발표 팁

- 슬라이드는 6장이면 충분: 표지 / 팀 / 문제 / 해결책 / 기술 구성 / 일정
- 해결책 슬라이드에서 실제 웹앱 진단 화면 스크린샷 1장을 보여주면 설득력이 오른다
- 질문 대비: "왜 클라우드가 아닌가", "정확도 93퍼센트의 약점은 무엇인가"(무 계열 두 병해 혼동, 데이터 확충 중), "SUDA를 못 쓰면 어떻게 하나"(오픈소스 대체 경로)
