# 우선순위 백로그

> 갱신: 2026-09-17. 대상: Orange Pi 5 Plus / RK3588 / 16GB.

최신 역할·선행 조건·완료 기준은 [역할별 이전 백로그](../operations/ORANGEPI5_MIGRATION_BACKLOG.md)에서 관리한다. 기존 P0~P3 순서는 아래로 대체한다.

1. 장치·패키지 확인, 모델 계약, ARM64 준비 (OP-01~03)
2. CNN CPU 배포와 성능 기준선 (OP-04~05)
3. RKLLM 예제 검증, Qwen 기본 모델 평가·변환·서빙 (OP-06~09)
4. 진단 JSON 연결, 스마트폰 접속, 화면·음성 통합 (OP-10~14)
5. 오프라인·재부팅·데이터 보존·전체 성능 검증 (OP-15~16)
6. 필요할 때 CNN 최적화·보조 모델 검증·LLM 파인튜닝 (OP-17~20)
7. 현장 시연 및 문서 확정 (OP-21)

CNN INT8과 다중 런타임 구현은 최초 배포의 필수 조건이 아니다. prepare_pair.py는 데이터 준비 도구이며 pair_mu.pth는 별도 학습으로 생성한다. SUDA 통합은 지원 확인 후 선택 검토한다.

학기 ID는 [스프린트 백로그](08_스프린트_백로그.md)에 유지한다. 보드 수령 즉시 첫 배포 검증을 진행한다.
