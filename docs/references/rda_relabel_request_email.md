제목: [한성대 학생 팀] 무 검은무늬병·노균병 공개 데이터 사진 42장 라벨 검토 요청

안녕하세요. 한성대학교 ○○학과 학생 김현영입니다.
저희 팀은 수업 과제로 고추·무·배추 잎 사진에서 병을 분류하는 스마트폰 앱(Cropy)을 만들고 있습니다.

학습에는 AI Hub 공개 데이터셋 "○○○"(노지 작물 질병 진단 이미지)을 쓰고 있는데, 무 검은무늬병과 무 노균병 두 라벨에서 모델 정확도가 다른 병보다 크게 낮습니다(검은무늬병 54%). 사진을 직접 살펴보니 검은무늬병 라벨이 붙은 사진 중 상당수가 회백색 반점에 갈색 테두리가 있는 노균병 양상으로 보이거나, 병반이 눈에 띄지 않았습니다. 다만 저희는 식물병리 전공이 아니라 사진만으로는 확신할 수 없어, 전문가 검토를 부탁드리고자 합니다.

요청 내용
- 첨부한 사진 42장(모두 잎 앞면, 2020년 10~11월 촬영)에 대해 검은무늬병 / 노균병 / 혼합 / 사진만으로 판정 불가 / 질병 아님 중 하나로 판정해 주시면 됩니다.
- 압축을 풀고 review.html을 브라우저로 열면 사진마다 숫자 키 하나로 판정할 수 있고, 끝나면 CSV로 내보내집니다. 30분 안팎 걸립니다.
- 가능하시다면 앞면 사진만으로 두 병을 구분할 때 보는 단서(병반 색·테두리·동심원 유무 등)를 한두 줄 적어 주시면 앱의 재촬영 안내 문구에 반영하겠습니다.

검토 결과는 학생 과제 보고서와 공개 저장소(GitHub)에 "전문가 검토 결과"로만 요약 기재하며, 성함은 허락하신 경우에만 적겠습니다. 바쁘신 중에 번거로운 부탁을 드려 죄송합니다. 어렵다면 담당 부서나 적합한 문의처를 알려 주셔도 큰 도움이 됩니다.
