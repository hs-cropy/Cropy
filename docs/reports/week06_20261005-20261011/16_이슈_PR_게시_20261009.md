## 커밋과 기반 정리

로컬 정리의 기능 단위 25개 커밋을 최신 원격 기준 또는 선행 작업 위로 적용했다. 기존 `ml` 브랜치를 보존하기 위해 모델 파트는 저장소에서 이미 쓰는 `model/...` 이름을 사용했다. 기존 작성자·한국어 커밋 규칙을 유지하고 도구의 공동 작성자 표기는 넣지 않았다. 카메라·음성 통합 수정 1개, UI 화면 자료 3개와 이번 게시 기록 1개를 추가해 제출 브랜치의 변경 커밋은 합계 30개다.

최신 develop의 카메라·이미지 검증·음성 안내와 기존 vitest 의존성을 보존했다. 백엔드는 농약 검증 PR #21을 기반으로 삼고, 문서 최신화는 기존 7주차 PR #40 위에 후속 변경만 쌓았다. 10월 8일의 [로컬 브랜치 정리 기록](15_기능별_브랜치_커밋_정리_20261008.md)은 게시 전 스냅샷이며, PR 제출용 기준과 링크는 이 문서를 따른다.
