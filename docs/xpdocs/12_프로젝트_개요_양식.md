## 프로젝트 개요

**제목: AI 기반 농작물 병해 진단 및 방제 지원 모바일·단말 서비스 (CropCare AI)**

**목표: 사진 한 장 또는 말 한마디로 병해를 진단하고 등록 농약까지 안내하는 농업인용 서비스 개발**

스마트폰 카메라 또는 독립 단말기로 고추·무·배추의 잎을 촬영하면 CNN 모델이 병해를 진단하고, 진단 결과에 맞는 등록 농약·희석배수·안전사용기준과 예방법을 즉시 안내하는 시스템을 개발합니다. 두 병해가 비슷하게 판정되어 구분이 어려운 경우에는 판별 부위(잎 뒷면 등)의 재촬영을 안내하고 두 사진을 함께 판단하여 정확도를 높입니다. 통신이 어려운 밭에서도 쓸 수 있도록 화면 없이 음성만으로 동작하는 오프라인 단말기(Orange Pi 5)까지 구현하는 것을 목표로 합니다.

## 추진 배경

**배경:**
- 농작물 병해는 조기 발견·조기 방제가 피해 규모를 결정하지만, 농업인 다수가 병해를 정확히 구분하지 못한다
- 병명을 알아도 등록 농약·희석배수·수확 전 사용금지 일수(PHI)를 찾는 과정이 번거로워 관행 살포로 이어진다
- 주 사용자인 고령 농업인은 작은 글씨·복잡한 앱·불안정한 통신 환경에서 스마트폰 앱을 쓰기 어렵다

**필요성:**
- 스마트팜·정밀농업 확산으로 AI 기반 병해 진단 수요가 증가하고 있으며, 농촌진흥청 등 공공기관도 이미지 기반 진단 서비스를 확대 중
- 농약 안전사용기준(PLS) 전면 시행으로 등록 농약·안전사용기준 준수가 의무화되어, 진단과 방제 정보를 한 번에 제공하는 서비스의 필요성 증대
- 농촌 고령화(주 사용자층 60대 이상)로 인해 음성 인터페이스·대형 글씨 등 접근성을 갖춘 서비스 요구 확대
- 온디바이스 AI(NPU 탑재 SBC)의 보급으로 통신 없이 현장에서 추론하는 단말 구현이 현실적으로 가능해짐

**선행사례:**
- 농촌진흥청 국가농작물병해충관리시스템(NCPMS): 병해 정보와 사진 진단을 제공하나, 사진 1장의 확률만 제시하고 농약 정보는 별도 검색이 필요하며 모바일 친화적이지 않음
- 일반 이미지 진단 앱(Plantix 등): 범용 작물 대상으로 국내 등록 농약·안전사용기준과 연결되지 않음
- 공통 문제점: 결과가 애매할 때(예: 무 검은무늬병 ↔ 무 노균병) 최상위 후보를 그대로 제시할 뿐, 사용자에게 "무엇을 더 봐야 하는지" 안내하지 않음. 실측 결과 오분류의 59%가 이 특정 두 병해 사이에서 발생했으며, 이는 모델 크기가 아니라 입력 사진에 판별 정보가 없어서 생기는 문제임

## 목표 및 내용

**개발목표:**
- 고추·무·배추 9클래스(병해 6종 + 정상 3종) CNN 진단 모델, test 정확도 90% 이상 유지
- 혼동쌍 발생 시 판별부위 재촬영을 안내하고 다시점 융합으로 재확정하는 적응형 진단 기능
- 진단 결과에 농약안전정보시스템(PSIS) 등록 농약·희석배수·PHI·예방법을 자동 연결하는 모바일 웹앱
- 화면 없이 음성만으로 동작하는 오프라인 진단 단말기(Orange Pi 5 + NPU) 및 양자화 모델

**개발내용:**
1. 사진 진단 (모바일 웹앱)
   작물 선택 → 촬영/업로드 → ResNet50 기반 CNN 분류
   Top-3 후보·신뢰도·심각도를 3탭 이내, 5초 이내에 제시
2. 혼동쌍 유도촬영 (핵심 차별점)
   상위 2후보가 사전 정의된 혼동쌍이고 신뢰도 차이가 좁으면 판별부위(잎 뒷면 등)와 관찰 단서를 문장으로 안내
   재촬영한 사진을 1차 결과와 융합하여 진단을 재확정하고, 이력에 두 사진과 재확정 여부를 함께 기록
3. 병해 정보 및 등록 농약 추천
   증상·원인·예방법 제공
   PSIS 기반 상표명·희석배수·사용시기·안전사용기준(PHI) 자동 연결
4. 진단 이력 및 접근성 UI
   진단 결과 자동 저장, 날짜별 목록·상세 조회
   큰 글자 토글, 원탭 촬영, 모바일 퍼스트 반응형 디자인
5. 오프라인 음성 진단 단말기
   Orange Pi 5(RK3588S NPU) + 카메라·마이크·스피커·버튼·LED
   버튼/음성 트리거 → 자동 촬영 → NPU 추론 → 결과 음성 낭독, 재촬영 음성 유도
   ONNX INT8 → RKNN 변환 및 양자화 모델 정확도 검증
6. 시스템 구성
   프론트엔드 Next.js, 백엔드 FastAPI + SQLite, ML PyTorch/ONNX Runtime/RKNN
   웹앱과 단말이 동일한 백엔드 코드를 사용하며, 단말은 백엔드를 보드 내부에서 로컬로 실행

**역할분담:**
- 김헌영 (PM · 모델): 일정 관리, 데이터셋 정제·증강, CNN 모델 학습·평가, ONNX export, 혼동쌍 분석, 모델 양자화(RKNN)·단말 추론 검증
- 김민서 (프론트엔드): 웹앱 화면 구현(홈·촬영·결과·이력), 디자인 시스템 적용, 모바일 반응형·접근성
- 박성호 (백엔드): FastAPI 추론 API, 진단 이력 저장, 농약 추천(PSIS) API, 웹앱 연동
- 고명준 (카메라 · 음성): 브라우저 카메라 모듈·촬영 가이드, 음성 안내(TTS/STT), 단말 카메라·마이크·스피커 통합
- 이서하 (백엔드 · 디바이스): 백엔드 배포·Docker·CI, 단말 로컬 서버 구성(오프라인 DB) 및 부팅 자동 실행, 디바이스 에이전트, RKNN 환경·NPU 배포, 부품 발주·검수, 전력·발열 측정

## 기대효과

- 병해 조기 진단으로 방제 시기를 앞당겨 수확량 손실을 줄이고, 잘못된 농약 선택·과다 살포로 인한 비용 낭비 감소 (경제적 측면)
- 등록 농약·희석배수·안전사용기준을 진단과 함께 제공하여 PLS 준수와 농산물 안전성 향상에 기여 (사회적 측면)
- 재촬영 안내 과정에서 사용자가 판별 부위를 학습하게 되어, 농업인 스스로 병해를 구분하는 역량 향상
- 음성 기반 오프라인 단말로 고령 농업인·통신 음영 지역 농가의 디지털 격차 해소
- 농업기술센터 지도사가 진단 이력(사진·날짜·재촬영 여부)을 근거로 상담할 수 있어 현장 지도 효율 향상
- 토마토·오이 등 작물 확장과 해충 클래스 추가로 다양한 작물·지역으로 적용 범위 확대 가능
