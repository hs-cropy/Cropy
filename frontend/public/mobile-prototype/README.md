## 실행

이 폴더의 `index.html`을 브라우저에서 열면 기본 시나리오를 볼 수 있습니다. 로컬 서버에서는 파일 선택과 브라우저 기능을 더 안정적으로 확인할 수 있습니다.

프로젝트 루트에서:

```powershell
node frontend/public/mobile-prototype/server.mjs
```

주소: http://127.0.0.1:4173

기존 Next.js를 실행 중이면 http://localhost:3000/mobile-prototype/index.html 에서도 열 수 있습니다. 추가 패키지 설치나 백엔드 실행은 필요하지 않습니다.

## 조작

사진 찍기 → 사진 확인 → 분석 → 결과 → 이력으로 이동합니다. 갤러리 선택은 실제 JPG/PNG 파일을 읽으며, 10MiB·4천만 픽셀 제한을 적용합니다. 사진은 브라우저 메모리에만 보관하며 서버로 전송하지 않습니다.

PC의 검토 패널 또는 휴대폰 상단의 '화면과 시나리오'에서 기본 화면 16개, 피드백 상태 24개, 오프라인 상태 10개를 선택할 수 있습니다. 분석 중·다운로드 중 등의 직접 선택 화면은 검토를 위해 해당 상태에 머무릅니다. 진단 버튼과 다운로드 안내 버튼으로 시작한 흐름은 예시 시간 경과에 따라 다음 화면으로 이동합니다.

큰 글자는 실제 확대됩니다. 음성은 지원 브라우저의 speechSynthesis를 사용하며, 실행 실패 시 토글을 복원합니다. 카메라 켜기는 사용자의 클릭 이후에만 실제 권한을 요청합니다. 기본 촬영 화면의 잎은 디자인 예시이며, 카메라 허용 전 사진 찍기를 누르면 이 예시 사진의 확인 화면으로 이동합니다.

## 시뮬레이션 범위

진단 결과·신뢰도·진단 기록·저장 알림은 예시입니다. 실제 AI 분석, 모델 다운로드, 기기 저장/서버 동기화, 농약 조회는 연결하지 않았습니다. 다운로드 진행률도 시뮬레이션입니다. 예시 진단 기록은 메모리에만 유지되고 새로고침 시 초기화됩니다.

오프라인 섹션은 준비/다운로드/로컬 저장/동기화의 UX 상태를 검토하기 위한 것입니다. 실제 오프라인 AI 실행이나 서비스 워커 설치를 의미하지 않습니다. 이미지·아이콘과 Pretendard 글꼴은 로컬 파일로 제공하며 임시 Figma 자산 URL을 런타임에서 호출하지 않습니다.

## 검증

Chrome에서 기본·오류·오프라인 41개 화면의 이미지, 가로 넘침, 내비게이션 및 콘솔 오류를 확인했습니다. 사진 확인 유지, 분석 취소, 결과 전환, 상세 정보 단일 펼침, 이력 필터, 저장 재시도, 업데이트 보류, 다운로드 완료 흐름을 확인했습니다. 실제 CSS 너비 390px에서 큰 글자와 하단 내비게이션을 확인했습니다.

실제 카메라 하드웨어·음성 재생 호환성·AI 정확도·휴대폰 기기 검증은 수행하지 않았습니다. 기존 애플리케이션 코드를 변경하지 않는 정적 프로토타입이므로 전체 백엔드/Next.js 빌드는 실행하지 않았습니다.
