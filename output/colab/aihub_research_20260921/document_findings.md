# 제공 설명서 확인 결과 — 2026-09-21

사용자가 추가한 가이드라인 PDF 57쪽과 ZIP 내부 PDF 2개(8쪽, 12쪽)를 확인했다. ZIP 내부 문서는 파일명 인코딩 혼선을 피하도록 `manual_1.pdf`, `manual_2.pdf`로 추출했고 원본 ZIP도 보존했다. 아래 쪽수는 PDF 뷰어 기준이다.

## 파일명 규칙: 기존 미확인 사항 해소

**구축 가이드라인 PDF 6쪽(인쇄 쪽수 4), 표 3·그림 2**를 이미지로 렌더링해 확인했다.

- 날짜 앞 필드는 수집 작업자 ID다. 따라서 현재 파일의 해당 위치에 있는 `5389e`, `2852e` 등은 문서 규칙에 대응시키면 작업자 코드이며, 농장이나 개체 ID로 사용해서는 안 된다.
- 날짜 다음 숫자는 촬영 순서다.
- 예시의 `S01`은 동일 객체 촬영 순서다. 전역적으로 고유한 객체 식별자가 아니므로 `S01`만 같은 이미지를 한 개체로 묶으면 안 된다.
- 그림은 과제 77 예시이고 문서 내 구분 표는 과제 79도 설명한다. 실제 노지 파일의 접미 구조가 예시와 완전히 같다고 가정하지 않는다. 현재 정상 파일에 보이는 `_S01_1`의 마지막 `_1` 의미 및 S 접미사가 없는 질병 파일의 개체 복원 규칙은 확인되지 않았다.

앞서 계산한 작업자+날짜 그룹은 **동일 개체 그룹이 아니라 수집 조건을 보수적으로 묶는 후보**로만 사용한다. 같은 작업자가 여러 장소·개체를 촬영했을 수 있다.

## 수집·좌표·증강

- 가이드라인 24쪽: 동일 개체를 여러 각도·거리에서 촬영할 수 있는 수집 지침이 있다. 유사하지만 바이트가 다른 사진의 분할 중복 가능성도 고려해야 한다. 현재 이미지가 모두 해당 방식으로 촬영됐다는 증거는 아니다.
- 가이드라인 40쪽: 병징을 보여주는 박스와 병징 잎 윤곽을 고려하는 지침, 객체/병징이 여럿이어도 박스 하나를 생성하는 안내가 있다.
- `manual_2.pdf` 8쪽: 관찰 대상 객체 추출을 위한 bbox를 제공한다고 설명한다. 따라서 bbox를 정밀 병반 마스크로 취급하지 않는다. 실제 좌표와 이미지를 검증한 후 객체 중심 크롭 실험에 활용할 수 있다.
- `manual_2.pdf` 3쪽: 질병 데이터를 10배씩 증강하여 별도 구축한다는 설명이 있다. 원본-증강 파일 대응을 복원하는 접미사 규칙은 이번 문서 확인에서 찾지 못했다.

## 다음 작업 결정

1. 이미 식별한 라벨 ZIP 18개를 확보하여 현재 이미지와 매칭한다. 설명서 업로드와 라벨 다운로드 완료는 구분한다.
2. 파일명 파서에서 작업자·날짜·촬영 순번·S 접미사·추가 접미사를 분리하고 알 수 없는 형식은 별도 표시한다.
3. 원본 해시 중복은 반드시 같은 분할에 둔다. 작업자 또는 작업자+날짜 기준 분할은 보수적 실험 설계 후보로 비교하되 개체 독립성을 입증했다고 표현하지 않는다.
4. 추가 접미사와 증강본 원본 매핑이 확인되기 전에는 `9.증강`을 새 평가셋에 섞지 않는다. 이후 온라인 증강은 train에만 적용한다.
5. 클래스마다 그룹 수와 비율을 확인한 뒤 새 분할을 고정하고 ImageNet 초기 가중치에서 224 기준선부터 학습한다. 기존 cropy 모델을 이어학습해 새 평가셋의 독립성을 주장하지 않는다.

새 데이터 분할이나 모델 학습은 아직 실행하지 않았다. 이번 작업은 문서의 정의 확인과 다음 분할 설계의 근거 정리다.
