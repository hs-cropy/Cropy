# AI Hub 공식 자료 조사 — 2026-09-21

> 후속: 사용자가 설명서 ZIP과 구축 가이드라인 PDF를 제공해 본문을 확인했다. 날짜 앞 코드는 작업자 ID, S01 위치는 동일 객체 촬영 순서로 정의되어 있다. 추가 접미사와 증강본 매핑은 미확인이다. [문서 확인 결과](document_findings.md) 참조. 아래 다운로드 실패 기록은 제공 전 조사 이력이다.

## 확인된 사실

- 대상은 [노지 작물 질병 진단 이미지, dataSetSn=147](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=147)다.
- 공식 소개에 원본 질병 사진에서 변환한 증강 이미지가 포함된다고 명시되어 있다. 새 분할에서는 동일 파일뿐 아니라 원본과 파생 이미지의 관계도 점검해야 한다(프로젝트 적용 판단).
- `region`은 촬영 지역, `date`는 취득일자다. 공개 표만으로 지역 코드별 명칭이나 개체 식별 규칙은 확인되지 않는다.
- `points`는 관심 객체의 bbox 좌표다. 관찰 대상 부위를 표시한다는 설명이며, 병반만 분리한 좌표라고 단정하지 않는다.
- `grow`는 11 육묘기·12 생장기·13 착화/과실기, `risk`는 0 정상·1 초기·2 중기·3 말기다.
- 샘플 데이터는 별도 가공되어 원본과 다를 수 있다고 안내한다. 로컬 JSON 360개가 해당 샘플에서 왔다는 사실까지 확인한 것은 아니다.

위 사실의 근거: 공식 페이지의 데이터 통계·어노테이션 포맷·샘플 안내. 공개 페이지를 `page.html`로 보관했다.

## 라벨 파일 식별 완료, 다운로드 미완료

공식 페이지가 사용하는 [파일 목록 API](https://www.aihub.or.kr/aihubdata/data/aJaxS3FileList.do)에 dataSetSn=147로 조회했다. 응답 126항목을 `file_list.json`에 보관했다. 고추·무·배추 라벨 18개는 `required_labels.csv`에 경로·파일키·크기를 기록했다. Training/Validation 각각 정상·질병·증강이 있다.

| 무 | 46512 / 46513 / 46514 | 46390 / 46391 / 46392 |

로컬 자료의 출처 범위가 완전히 확정되지 않았으므로 양쪽 라벨을 확보한 뒤 파일명으로 매칭하는 것이 다음 작업이다. 이미지 전체 재다운로드부터 할 필요는 없다. 공식 페이지는 데이터 다운로드 승인 후 API 이용이 가능하다고 안내한다. 사용자 계정의 승인 상태는 확인하지 않았다.

## 아직 확인되지 않은 사항

날짜 앞 코드(`5389e`, `2852e` 등), `S01`, 증강본의 원본 추적 규칙은 공개 소개·검색에서 확인하지 못했다. 다른 데이터셋의 명명 규칙을 적용하지 않는다.

[데이터 설명서](https://www.aihub.or.kr/file/down.do?fileSn=8154&dataMnlFileSn=8154&dataSetSn=147), [구축활용가이드](https://www.aihub.or.kr/file/down.do?fileSn=8155&cnstcPrcuseFileSn=8155&dataSetSn=147) 링크는 존재하지만 직접 다운로드는 오류 응답을 반환했다. 설명서 본문을 읽었다고 주장하지 않는다. 오류 HTML은 별도 보관했고 PDF로 오인하지 않게 이름을 변경했다. 로그인 필요 여부가 해당 오류의 원인이라고 확정할 수 없다.
