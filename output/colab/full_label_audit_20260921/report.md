# 전체 라벨 연결 결과 — 2026-09-21

## 완료 사항

사용자가 제공한 TAR 18개 내부의 ZIP.part0를 메모리에서 읽고 ZIP CRC를 검사했다. 각 파일은 단일 part0만으로 정상 ZIP을 구성한다. 라벨 JSON 91,041개를 파싱했으며 오류는 없다. 다운로드 자료와 기존 이미지는 수정하지 않았다. 함께 제공된 AI 모델 ZIP은 이번 라벨 연결에 사용하거나 실행하지 않았다.

현재 dataset 4,246장 모두 `description.image`의 파일명(확장자 제외, 대소문자 정규화)으로 라벨이 정확히 하나씩 연결된다. 미매칭 0, 다중 매칭 0. 기존 128장 연결에서 전체 연결로 개선됐다. 파일명 매칭이 이미지 내용의 올바른 라벨링까지 보장하지는 않는다.

## 출처 분할 확인

| 현재 프로젝트 분할 | 공식 Training 출처 | 공식 Validation 출처 |
|---|---:|---:|
| train | 1,713 | 1,259 |
| val | 371 | 266 |
| test | 364 | 273 |
| 합계 | 2,448 | 1,798 |

이는 연결된 라벨 ZIP 경로를 기준으로 복원한 출처다. 현재 프로젝트 분할은 공식 분할을 섞어 다시 구성되어 있다. 혼합 사실만으로 유사 이미지 누출 전부를 증명하지는 않지만, 앞서 확인한 원본 바이트 중복 6쌍은 별도의 확정 증거다.

**고추·무·배추 정상 이미지는 각각 500장 전부 공식 Validation 출처다.** 현재 4,246장만 공식 분할대로 재배치하면 학습셋의 정상 클래스가 사라진다. 공식 분할을 활용하려면 Training 정상 원천 이미지 확보가 선행되어야 한다.

현재 이미지의 라벨은 정상 1,500장 및 질병 2,746장 묶음에 연결됐고 `9.증강` 묶음에 연결된 것은 없다. 이는 공식 파일 범주를 확인한 것이며 현재 이미지 전부가 독립 촬영본임을 입증하지 않는다.

## 불일치 2건

병해·작물·부위·생육·위험도 코드와 파일명 토큰은 모두 일치한다. 날짜 불일치 2건은 모두 무 정상 train 이미지다.

- `V006_79_0_00_02_03_12_0_c11_202012223_0009_S01_1.jpg`
- `V006_79_0_00_02_03_12_0_c11_202012223_0013_S01_1.jpg`

두 파일 모두 날짜 토큰이 9자리 `202012223`이고 JSON date는 빈 문자열이다. 임의로 날짜를 추정해 고치지 않았다. 날짜 기반 그룹을 설계할 때 미확인 그룹으로 처리하고 평가용 배정을 피하는 방안을 검토한다.

## 증강 파일 관찰

증강 라벨 예시에는 원래 파일명 뒤에 `_a0000`, `_a0001` 등의 접미사가 있다. `augmentation_examples.json`에 예시 5개를 기록했다. 접미사를 제거한 이름이 전체 증강 자료에서 원본과 1:1로 대응하는지 검증하지 않았으므로 확정 매핑 규칙으로 적용하지 않는다.

## 다음 작업

1. 현재 라벨 연결표로 클래스별 작업자·날짜 그룹 수를 집계하고, 원본 해시 중복을 함께 고려한 새 분할 후보를 계산한다. 작업자를 개체 ID로 부르지 않는다.
2. 현재 이미지만 보수적으로 재분할하는 방안과 공식 Training 정상 이미지를 추가 확보하는 방안을 비교한다. 공식 분할 자체의 그룹 독립성도 자동으로 가정하지 않는다.
3. 분할 확정 후 ImageNet 가중치에서 새 224 기준선을 학습한다. 이미 기존 train으로 학습한 cropy 모델로 새 평가셋의 독립성을 주장하지 않는다.
