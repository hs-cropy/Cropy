# 학습 크롭 제거 비교 실험

목적: 무노균병의 낮은 검증 재현율에 학습 중 무작위 크롭이 영향을 주는지 확인합니다.

## 실행

실행용 노트북: [Colab에서 열기](https://colab.research.google.com/drive/1HGqC1kw62DBzLmMGoTrXBxNh_yIkSzMC)

1. `cropy_full_resize_colab.ipynb`를 Colab에서 엽니다.
2. 런타임을 T4 GPU로 선택한 뒤 **모두 실행**합니다.
3. Drive 연결 화면이 나오면 기존 데이터가 있는 계정으로 연결합니다.

기존 Drive의 `MyDrive/cropy_full_512/cropy_full_512.zip`을 재사용합니다. 노트북에 학습 코드가 포함돼 있어 데이터나 코드 ZIP을 다시 업로드할 필요가 없습니다. 기존 모델 폴더 `cropy_runs/full512_resnet50_v1`은 비교용으로 읽습니다. 새 학습 결과는 `cropy_runs/full512_resnet50_full_resize_v1`에 저장합니다.

## 변경과 고정 조건

학습 전처리 첫 단계만 `RandomResizedCrop(256, scale=(0.7, 1.0))`에서 `Resize((256, 256))`로 변경합니다. 기존 좌우 반전, 15도 회전, 색상 증강, 정규화와 검증 전처리를 유지합니다. 회전으로 모서리가 잘릴 가능성은 남아 있습니다.

ResNet50, 입력 256px, batch 16, 20 epoch, seed 42, 클래스 균형 샘플링, AdamW 설정, 데이터 분할, 최고 모델 선택 기준(검증 Macro F1)을 유지합니다. 기존 모델을 미세조정하지 않고 동일한 ImageNet 가중치에서 시작합니다. 전처리가 달라지므로 같은 seed라도 난수 소비 순서는 달라질 수 있습니다.

기존 환경은 PyTorch `2.11.0+cu130`, Tesla T4입니다. PyTorch 버전이 다르면 노트북이 학습 전에 중단합니다. GPU 차이는 표시하며, 라이브러리와 GPU가 달라진 결과를 크롭만의 효과로 단정하지 않습니다.

## 중단 후 재개와 비교

연결이 끊기면 같은 설정으로 위에서부터 다시 실행합니다. `last_checkpoint.pth`에 저장된 마지막 완료 epoch부터 이어 갑니다. 설정이 다른 체크포인트로 재개하는 경우 중단합니다.

학습이 모두 끝나면 `comparison/comparison.md`와 `comparison/comparison.json`을 새 결과 폴더에 저장합니다. 전체 정확도·Macro F1, 9개 클래스 정밀도·재현율·F1 및 주요 혼동을 비교합니다. 무노균병 24장은 한 장 차이가 약 4.17%p이므로 재현율만으로 모델 교체를 결정하지 않습니다. 분석에 사용한 검증셋의 결과이며, 별도의 독립 테스트 결과가 아닙니다.

20에폭 학습과 비교를 완료했습니다. 두 실행의 최고 에폭은 모두 3입니다. 기존/크롭 제거 모델의 정확도는 모두 99.4349%, Macro F1은 각각 0.960803/0.959030이며, 무노균병은 모두 19/24 정답(79.17%)입니다. 기존 모델을 유지합니다. 전체 비교 원자료는 `comparison.json`, 후속 파일별 대조는 [무 질병 비교 결과](../radish_pair_review_20261005/README.md)에 있습니다.

## 준비 검증

`backend/.venv/Scripts/python.exe -m pytest ml/tests -q`: 29개 통과. 노트북 코드 셀 컴파일과 포함된 소스의 해시 일치를 확인했습니다.

소규모 CPU 점검(ResNet18, 64px, 학습 18장·검증 18장)에서 연속 학습과 중단 후 재개의 모델·옵티마이저·스케줄러·난수 상태·학습 이력이 정확히 일치했습니다. 서로 다른 크롭 설정으로 재개하면 기존 파일을 변경하지 않고 거부합니다. 이 점검 수치는 실제 개선 실험 성능이 아닙니다.
