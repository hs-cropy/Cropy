# 256 입력 실험 결과 비교 — 2026-09-24

새 결과는 기존 224 입력보다 소폭 개선됐지만, 무 병해 구분은 여전히 취약하다. 서비스 모델은 교체하지 않았다.

| 지표 | 224 기준선 | 256 실험 |
|---|---:|---:|
| 최고 epoch | 20 | 19 |
| 검증 정확도 | 91.85% (721/785) | 92.48% (726/785) |
| Macro F1 | 0.9035 | 0.9099 |
| 오분류 | 64 | 59 |
| 병해 → 정상 오분류 | 29 | 22 |
| 무 두 병해 간 혼동 | 28 | 31 |
| 배추노균병 → 배추정상 | 14 | 11 |

정확도는 **0.64%p**, Macro F1은 **0.0064** 증가했다. 동일 표본별로 기존 오류 17건을 맞혔고, 기존 정답 12건을 새로 틀려 순증가는 5건이다. 단일 seed의 검증 결과만으로 안정적인 성능 우위를 확정하지 않는다.

## 클래스별 재현율

| 클래스 | 224 | 256 | 256 정답/표본 |
|---|---:|---:|---:|
| 고추탄저병 | 90.91% | 91.92% | 91/99 |
| 고추흰가루병 | 94.06% | 98.02% | 99/101 |
| 무검은무늬병 | 81.61% | 77.01% | 67/87 |
| 무노균병 | 69.39% | 73.47% | 36/49 |
| 배추검은썩음병 | 97.26% | 97.26% | 71/73 |
| 배추노균병 | 76.47% | 80.88% | 55/68 |
| 고추정상 | 100.00% | 99.08% | 108/109 |
| 무정상 | 100.00% | 100.00% | 87/87 |
| 배추정상 | 100.00% | 100.00% | 112/112 |

무검은무늬병 → 무노균병은 14건에서 19건으로 늘고, 반대 방향은 14건에서 12건으로 줄었다. 정상으로 놓친 병해는 줄었지만 22건이 남아 있으므로 정상 결과를 무병 확정으로 표시하면 안 된다. 입력 해상도 증가만으로 가장 취약한 구분이 해결되지는 않았다.

## 검증

두 ZIP의 CRC, 분할 manifest SHA256 일치, 검증 예측 785개 경로와 정답, 혼동행렬, 정확도와 Macro F1 재계산, 20 epoch 기록과 최고 epoch 선택을 확인했다. seed·초기화·샘플링·학습률 등 주요 학습 설정도 같다. 체크포인트는 `weights_only=True`로 읽어 모델 구조·클래스·입력 크기·epoch 및 가중치의 유한성을 확인했다. 전체 이미지의 로컬 재추론과 test 평가는 수행하지 않았다.

작업자 분리는 개체·농장 독립성을 보장하지 않는다. 특히 무노균병 검증 표본은 기존과 같은 작업자 1명의 49장이므로 일반화 해석에 주의한다. 반복적으로 같은 val을 보고 실험을 선택한 만큼 최종 성능은 별도 test로 확인해야 한다.

## 다음 판단

256 모델은 후보로 보존한다. 우선 `paired_predictions.csv`의 새 오류 12건과 무 병해 혼동 31건을 원본·라벨 기준으로 검토한다. 모델 오류만으로 라벨을 바꾸지 않는다. 모델 선택을 확정한 다음 보류한 test를 평가하고, Orange Pi에서 지연시간·메모리를 측정한 뒤 배포를 결정한다. 입력 픽셀 수는 약 30.6% 증가하지만 실제 지연시간은 측정 전에는 알 수 없다.

백엔드에는 체크포인트 입력 크기와 모델 해시 기록, 정상 결과의 불확실성 안내, 무 병해 재촬영 정보를 보존하는 수정이 반영되어 있다. 이번 결과만으로 신뢰도 임계값이나 별도 pair 모델을 바꾸지는 않았다.
