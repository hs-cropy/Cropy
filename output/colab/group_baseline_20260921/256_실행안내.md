# 256 입력 비교 실험

1. Colab에서 `C:\cropy\ml\cropy_group_256.ipynb`를 업로드한다.
2. 이전과 같은 T4 GPU를 선택한다. 기존 Drive `cropy/cropy_group_baseline_bundle.zip`을 그대로 사용하므로 대용량 ZIP 재업로드는 필요 없다.
3. 1번 셀에서 Drive 연결 및 데이터 검증·압축 해제를 진행한다. 최신 학습 실행기는 노트북에 포함되어 기존 ZIP의 실행기를 해당 Colab 작업 폴더에서 대체한다.
4. 2번 셀을 실행한다. ImageNet V2부터 새 학습, seed 42, batch 32, 20 epoch, 일반 샘플링이며 입력 크기만 256이다. 이전 cropy 가중치를 사용하지 않는다.
5. 3번 셀에서 전체 정확도·macro F1·클래스별 재현율을 224 결과와 비교한다.
6. 4번 셀에서 결과 ZIP을 다운로드해 `C:\cropy\output\colab`에 넣는다. 이 셀은 런타임 초기화 후에도 독립 실행 가능하며 결과 폴더가 하나이면 자동 선택한다.

결과 위치는 `내 드라이브/cropy/results_256/<실행시각>`이다. 학습이 끊기면 자동 이어학습은 지원하지 않는다. 메모리 부족 시 오류를 확인하고, batch를 낮춰야 한다면 224도 동일 batch로 재실험해야 입력 크기만 바꾸는 비교가 된다. 라이브러리 버전과 GPU는 config에 기록된다. 224 실행 환경은 torch 2.11.0+cu128, torchvision 0.26.0+cu128, Tesla T4였으며 환경이 달라지면 비교에 추가 변수가 있음을 기록한다.

224 기준선: val 721/785 = 91.85%, macro F1 0.9035. 무검은무늬병 81.61%, 무노균병 69.39%, 배추노균병 76.47% 재현율. 전체 val에 대한 지표와 새로 틀린 사례도 검토한다. test 평가 셀은 이 노트북에 포함하지 않았다.

현재는 실행 준비 단계다. 로컬 코드 점검은 GPU 학습이나 256 정확도 검증을 대신하지 않는다.
