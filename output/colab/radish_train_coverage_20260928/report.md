# 무 병해 학습 데이터의 촬영면·시각 특징·환경 조사

조사일: 2026-09-28 · 기준: 작업자 분리 번들의 train · 대상: 무검은무늬병/무노균병

## 1. 판단

**촬영면과 환경의 일부 조건은 학습에 이미 포함되어 있다. 그러나 두 병해를 안정적으로 구별하기에 충분하다고 판단할 근거는 아직 부족하다.** 잎 뒷면·근접 촬영·그림자·손·갈색 부위·구멍은 두 클래스의 표본에서 모두 확인했다. 따라서 검증 오류를 단순히 “뒷면 사진이나 그림자 사진이 학습에 없어서 발생했다”고 설명할 수 없다.

확인된 제약은 무노균병의 적은 사진 수와 작업자 범위, 표본에서 겹쳐 보이는 시각적 특징, 촬영면 비율 차이다. 사진의 병리학적 병징·발병 단계·동일 개체를 확정하지 않았으므로 이 제약이 오분류의 직접 원인이라는 결론은 아니다.

## 2. 범위·방법

- manifest의 `candidate_split=train` 및 클래스 2/3만 골라 **513장 전체의 메타데이터**를 조사했다. 원본 파일 존재·실제 치수·라벨 코드 및 클래스 연결을 확인했다.
- `클래스 × 파일명 작업자 ID × 날짜`의 **65개 묶음마다 1장**, 경로 SHA256 정렬의 첫 표본을 선정해 **65장 시각 검토**를 수행했다. 513장 전부를 육안 검토한 것은 아니다.
- 작은 묶음과 큰 묶음에서 동일하게 1장씩 골랐으므로 시각 집계는 사진 수에 비례한 무작위 표본이 아니다. 아래 비율을 전체 train의 비율로 환산하지 않는다.
- 65장 모두 파일 해시가 manifest와 일치한다. 촬영면은 미리보기에서 잎맥·접힘 등을 보고 추정했으며 불확실한 사진은 판단 불가로 남겼다. 보이는 갈색 점·황변·구멍은 질병 특이적 병징으로 확정하지 않았다.
- 라벨은 기존 전체 라벨 조사에서 추출한 로컬 캐시를 사용했다. 작물 코드 2 및 질병 코드 3/4와 클래스가 모두 일치했고, 실제 이미지와 라벨 치수의 불일치는 513장 중 0장이었다.
- 비교 대상은 이전에 조사한 val 오류·정답 기록이다. train과 val의 무 병해 작업자 및 동일 SHA256 교집합은 각각 0이었다. 농장·개체·파생 이미지의 독립성을 새로 입증한 것은 아니다.
- 새 분할의 test 사진은 열거나 평가하지 않았다. 원본 경로의 과거 train/val/test 폴더명 대신 manifest의 현재 분할을 사용했다. 학습·모델 추론·라벨 수정·데이터 이동·원격 업로드는 하지 않았다.

manifest SHA256: `d0fda6ef2e51b7ea1a201941e10dadea2f8e6b33eca785735b3d0dec58620e72`.

이 집계는 **육안 추정한 표본 분포**다. 촬영면을 확정하는 원본 메타데이터나 전문가 합의는 확보하지 않았다. 한 묶음의 선택 사진이 뒷면이라고 해서 같은 묶음의 모든 사진을 뒷면으로 계산하지 않았다.

| 조건 | 실제 관찰 예시 | 판단 |
|---|---|---|
| 잎 뒷면·잎맥 | T01~03, T26~27 / T45~46, T53, T60 | 두 클래스 모두 포함됨. 뒷면 자료 부재 가설은 지지되지 않음 |
| 앞면으로 보이는 잎 | T20~22, T24, T28 / T44, T47, T58~59, T64~65 | 두 클래스 모두 표본에 존재. 표본에서 비율 차이는 있으나 전체 비율 미확정 |
| 작은 갈색·밝은 점 | T07, T15, T26 / T45, T53, T57 | 두 클래스에서 겹쳐 보임. 어떤 차이가 질병 구분 근거인지 전문가 검수 필요 |
| 황변·큰 갈색 부위 | T24, T29, T33 / T52, T61 | 일부 존재. 발병 초기/중기/말기 분포나 중증도는 판정하지 않음 |
| 구멍·가장자리 손상 | T10, T13, T17 / T44, T46~47, T65 | 두 클래스에 존재. 병해·벌레·물리 손상 여부를 사진만으로 확정하지 않음 |
| 손·장갑 | T02~03, T22, T31 / T45, T55, T60 | 두 클래스에 존재. 손 배경 제거만으로 개선될 것이라는 근거 없음 |
| 강한 명암·그림자 | T02, T15, T33, T38 / T49, T51, T58, T63 | 두 클래스 모두 포함됨. 촬영 광량 다양성의 충분성은 별도 확인 필요 |

“조건이 한 번 이상 보인다”는 것과 “조건별로 학습이 충분하다”는 것은 다르다. 근접한 동일 잎 여러 장보다 서로 다른 개체·환경의 사례가 필요하지만, 이번 조사로 독립 개체 수까지 계산할 수는 없다.

## 5. 기존 val 오류와 대조

이전 [오류 59장 검토](../error_review_256_20260928/report.md)에서 무 두 병해 상호 혼동은 31건이었다. 이번에는 그 자료를 다음과 같이 해석한다.

| val 관찰 | 대응하는 train 표본 | 해석 |
|---|---|---|
| 뒷면·작은 국소 변화(E11~14, E33~34 등) | T07~19, T37~43, T53~57 | 유사한 넓은 조건은 학습에 있음. 조건 부재보다 세부 패턴·라벨 기준·독립 사례 다양성을 확인할 필요 |
| 손과 강한 그림자(E16, E39, E41~42 등) | T02, T15, T33, T38, T49, T63 | 손·그림자가 낯선 조건이라고 단정할 수 없음 |
| 큰 황변·갈색 반점이 보이는 새 오류(E30) | T24, T26~29, T33 | 큰 시각 변화도 학습 표본에 있음. 같은 질병의 변화 범위와 다른 병해의 구별 기준 검수 필요 |
| 무검은무늬병 val 작업자별 오류 차이 | train 작업자는 별도 6명 | train·val 작업자 분리는 유지됨. 작업자 효과와 질병 상태·촬영면 차이가 얽혀 있어 인과 판단 불가 |

대응 표본은 정량적인 최근접 검색 결과가 아니라 관찰 특징의 예시다. 무노균병 val은 작업자 3055e 한 명의 49장이고, train은 다른 3명이다. 새로운 환경에서의 성능을 넓게 판단하기에는 평가 범위도 제한된다.

## 6. 보강·검수 우선순위

1. **무노균병의 독립 사례 범위를 넓힌다.** 기존 3명·특정 작업자에 집중된 연속 사진을 단순 복제하기보다 새로운 작업자·장소·개체의 사진을 우선 확보한다. 사진마다 개체·장소·날짜·촬영면을 기록하고 같은 개체는 동일 분할에 둔다. 현재 자료만으로 필요한 장수를 확정하지 않는다.
2. **두 병해의 구별 근거를 검수한다.** T15/T26/T29와 T52/T53/T57처럼 국소 갈색·밝은 부위가 있는 사례를 전문가에게 원본으로 비교 요청할 후보로 둔다. 정상·다른 손상과의 구별도 포함하며 모델 예측만으로 라벨을 바꾸지 않는다.
3. **촬영 조건을 클래스 양쪽에 맞춰 수집한다.** 동일 개체의 앞면·뒷면, 잎 전체·국소 근접을 대응해 수집한다. 자연광·그늘·손 유무를 한쪽 병해에만 몰아넣지 않는다. 무검은무늬병 앞면은 이번 표본에서 적었으므로 전체 train에 대한 추가 태깅 대상으로 삼는다.
4. **실제 서비스 사진의 조건을 따로 확인한다.** 스마트폰 거리·배경·흐림·빛 반사 사례를 수집해 현재 train과 비교한다. 이번 사진만으로 현장 환경을 충분히 포함했다고 표시하지 않는다.
5. **재학습 전에 평가 기준을 고정한다.** 분할·중복 검사와 라벨 검수 후 기존 학습 대비 변경 하나씩 비교한다. 전체 정확도뿐 아니라 무 두 병해 재현율·혼동 건수를 기록한다. 기존 val을 train으로 옮기거나 보류 test를 개발용으로 사용하지 않는다.

다음의 가장 작은 작업은 **무 두 병해에서 구별이 애매한 원본의 전문가 검수 후보를 확정하고, 촬영면 태깅을 나머지 train 사진으로 확대하는 것**이다. 이번 조사에서 확인한 불균형은 후보 원인이지 재학습 성능 향상을 보장하는 증거가 아니다.
