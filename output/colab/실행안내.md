# cropy 3주차 Colab 실험

1. Colab에서 `ml/cropy_week3.ipynb`를 업로드해 연다.
2. GPU 런타임을 선택한다.
3. 첫 코드 셀을 실행하고 `output/colab/cropy_week3_bundle.zip`을 선택한다.
4. 기준 모델 val 평가와 무 병해 오류 그림을 확인한다. 오류 메모를 작성한다.
5. 이어학습 셀을 실행한다. 일반 샘플링과 균형 샘플링을 각각 동일 시작 모델로 학습한다.
6. val 비교표를 검토한다. test는 기본적으로 실행하지 않는다.
7. 마지막 셀로 결과 ZIP을 다운로드한다. 런타임 종료 전에 반드시 저장한다.

## 실험 조건

- 기존 체크포인트와 기존 Colab 번들의 축소 이미지를 사용한다. 데이터 분할은 바꾸지 않는다.
- 축소 이미지 결과는 문서의 원본 이미지 정확도와 직접 비교하지 않는다.
- 기존 모델 입력 크기를 유지한다. img_size가 없으면 현재 서비스와 동일하게 224를 사용한다.
- 두 실험은 seed 42, 학습률 2e-5, 12 epoch, batch 32를 기본으로 한다.
- 학습 코드는 전체 val 정확도가 기준 모델보다 개선될 때만 새 모델을 저장한다. 개선이 없으면 기준 모델을 유지한다.
- 후보 결정에는 전체 정확도와 무 두 클래스 정확도를 함께 검토한다. 단일 seed 결과만으로 일반화된 개선을 주장하지 않는다.
- test는 후보와 선택 근거를 확정한 뒤 선택 셀에서 명시적으로 활성화한다.
- 기존 로컬 모델이나 배포 모델을 자동 교체하지 않는다.
- Colab GPU 결과는 Orange Pi CPU/NPU 실측 결과가 아니다.

## 준비 검증 범위

노트북 코드 셀 문법, ZIP 무결성, 번들 체크포인트 해시를 로컬에서 확인했다.
Colab GPU 학습은 아직 실행하지 않았다. 첫 실행에서 클래스 순서와 체크포인트 메타데이터도 확인한다.

Qwen 평가 노트북은 이번 CNN 실험 범위에 포함하지 않는다. 먼저 비교 결과를 확보한다.
