# 전체 데이터 시험 학습

중복 제거된 데이터에서 클래스별 학습 20장·검증 10장을 선택해 ResNet18을 CPU로 2 epoch 학습했다. 총 학습 180장, 검증 90장이며 기존 학습 코드의 변환·손실·학습·평가 함수를 사용했다. 기존 Cropy 모델을 이어 학습하지 않고 ImageNet 가중치에서 시작했다.

| Epoch | 손실 | 학습 정확도 | 소규모 검증 정확도 |
| --- | ---: | ---: | ---: |
| 1 | 1.8469 | 36.11% | 68.89% |
| 2 | 1.0502 | 83.33% | 82.22% |

가중치 갱신, 유한한 손실·파라미터, 체크포인트 저장 및 재로딩 후 출력 일치를 확인했다. 소요 시간: 83.56초.

**이 수치는 전체 데이터의 성능이나 기존 모델 대비 개선 결과가 아니다.** 최종 테스트는 사용하지 않았으며 본 학습도 수행하지 않았다. 서비스 모델을 교체하지 않았다.
