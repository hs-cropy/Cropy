# 농작물 병해 진단 AI 모델 개선 보고서

**프로젝트:** cropy · **팀명:** 크래파스 · **작성자:** 김헌영(PM·모델)

**작성일:** 2026년 10월 6일 · **분석 대상:** 기존 모델과 256·384 입력 크기 미세조정 모델

## 1. 보고 목적과 주요 결과

고추·무·배추의 병해 6종과 정상 3종을 구분하는 ResNet50 모델에 대해, 기존 최고 가중치에서 입력 크기 256과 384로 각각 5에폭 추가 학습한 결과를 비교하였다. 제공된 최고 모델 파일과 Google Drive의 학습 로그·최종 비교 문서를 대조하여 완료 기록과 선택 에폭을 확인하고, 저장된 혼동행렬에서 성능 지표를 재계산하였다. 본인의 수행 범위는 데이터 준비, 학습·평가 환경 구성, 오분류 분석과 모델 비교이다. [S1, S8]

**256 미세조정 모델은 전체 검증 지표가 가장 높았지만, 목표였던 무노균병 재현율 개선에는 이르지 못했다.** 기존 대비 정확도는 99.4349%에서 99.5823%, Macro F1은 0.960803에서 0.962436으로 상승하였다. 반면 무노균병 정답 수는 24장 중 19장에서 17장으로 줄었다. 384 모델은 정확도 99.5577%, Macro F1 0.960005이며, 무노균병 정답은 15장이었다. [S1, S2]

전체 Macro F1을 기준으로는 256 모델이 우세한 후보이다. 다만 무노균병을 놓치는 문제가 악화되었으므로 서비스 모델의 즉시 교체를 보류하고, 기존 모델과 새 후보를 함께 보존하는 것이 타당하다. 본 보고서 작성 과정에서 서비스 모델이나 진단 기준을 변경하지 않았다.

## 3. 실험 설계와 분석 범위

### 3.1 비교한 세 모델

기존 기준 모델은 입력 256으로 20에폭 학습한 실행의 3에폭 모델이다. 256·384 미세조정은 이 모델의 동일한 가중치에서 새로 시작하며, 두 실행의 저장 설정은 입력 크기를 제외하고 일치한다. 원본 모델과 미세조정 모델은 학습률과 학습 단계가 다르므로, 입력 크기의 비교는 256·384 미세조정 사이를 중심으로 해석한다. [S1, S2]

| 항목 | 256 미세조정 | 384 미세조정 |
|---|---|---|
| 모델 | ResNet50, 9개 클래스 | 동일 |
| 시작 가중치 | 기존 최고 모델, 원본 3에폭 | 동일 |
| 모델 입력 | 256×256 | 384×384 |
| 완료 / 계획한 추가 학습 | 5 / 5에폭 | 5 / 5에폭 |
| 학습률 / batch / seed | 0.00001 / 16 / 42 | 동일 |
| 샘플링 / 학습 전처리 | 클래스 균형 / 무작위 크롭 | 동일 |
| 모델 선택 기준 | 검증 Macro F1 최대, 동률 시 앞선 에폭 | 동일 |
| 제공된 모델의 선택 에폭 | 추가 학습 4에폭 | 추가 학습 1에폭 |

학습 코드에는 AdamW, cosine 스케줄러, weight decay 0.0001, label smoothing 0.1과 반전·회전·색상 증강이 사용된다. 옵티마이저·스케줄러는 원본 학습 상태를 이어받지 않고 새로 시작하도록 구성하였다. 학습 전 epoch 0도 모델 선택 대상이나, 이번에 제공된 두 파일은 모두 학습 후 에폭에서 선택된 모델이다. [S4]

Colab 전달용 이미지는 긴 변을 최대 512픽셀로 축소한 사본이고 원본은 별도로 보존하였다. 모델 폴더명의 **full512는 입력 512를 의미하지 않는다.** 기준 모델의 실제 입력은 256이며 이번 비교 입력은 256과 384이다. [S5]

### 3.2 모델 파일과 Drive 실행 기록의 대조

분석 파일은 `output/256_384/256_best_model.pth`와 `384_best_model.pth`이다. 안전한 가중치 전용 로딩을 사용했으며, 9클래스 ResNet50 구조와의 엄격한 일치, 가중치의 유한성, 클래스 순서, 검증 표본 수, 시작 모델과 데이터 목록의 해시 기록을 확인하였다. 두 파일의 시작 모델 해시는 이전에 저장한 기준 모델 감사 기록과 일치한다. [S1]

로컬 모델 파일에 더해 Drive의 `comparison.md`, `training_256.log`, `training_384.log`를 확인하였다. **두 로그의 에폭 1~5 기록과 5에폭 저장 완료 문구, 최종 비교 문서의 5/5 상태가 일치한다.** 문서에 기록된 최고 에폭 4·1, 설정과 혼동행렬도 로컬 모델과 일치하였다. 384 실행은 2에폭 뒤 중단되고 3에폭부터 재개하여 5에폭까지 완료된 로그가 남아 있다. [S8]

보고서 수치는 저장된 혼동행렬을 재계산한 결과이며, 4,070장을 다시 추론해 재현한 수치나 독립 테스트 결과는 아니다. 최종 비교 문서의 환경 필드는 두 실행 모두 PyTorch 2.11.0+cu130, CUDA, Tesla T4로 일치한다. 이는 기록된 항목의 일치이며 전체 라이브러리·하드웨어 조건의 완전한 동일성까지 보증하지 않는다. [S8]

## 4. 전체 성능과 클래스별 재현율

### 4.1 제공된 최고 모델의 전체 지표

같은 클래스 순서와 검증 표본 수 4,070장을 기준으로 비교하였다. Macro F1은 0~1 척도이며, 클래스별 F1을 같은 비중으로 평균한 값이다. [S1, S2]

| 지표 | 기존 기준 모델 | 256 미세조정 | 384 미세조정 |
|---|---:|---:|---:|
| 저장된 선택 에폭 | 원본 3 | 추가 4 | 추가 1 |
| 검증 정답 수 | 4,047 | 4,053 | 4,052 |
| 전체 오분류 | 23 | 17 | 18 |
| 검증 정확도 | 99.4349% | 99.5823% | 99.5577% |
| Macro F1 | 0.960803 | 0.962436 | 0.960005 |
| 기존 대비 정확도 변화 | 기준 | +0.1474%p | +0.1229%p |
| 기존 대비 Macro F1 변화 | 기준 | +0.001633 | -0.000799 |

256 모델은 기존보다 총 정답이 6장 늘었고 Macro F1도 상승했다. 384 모델은 기존보다 총 정답이 5장 늘었지만 Macro F1은 소폭 낮아졌다. 384와 256을 직접 비교하면 384의 정확도가 0.0246%p, Macro F1이 0.002432 낮았다. 선택 에폭이 서로 다르므로 동일 학습 기간의 마지막 모델 비교와는 구분한다.

### 4.2 클래스별 재현율

재현율은 해당 클래스의 실제 사진 중 올바르게 분류한 비율이다. 표의 값은 소수 둘째 자리로 반올림하였다.

| 클래스 | 검증 표본 | 기존 기준 모델 | 256 미세조정 | 384 미세조정 |
|---|---:|---:|---:|---:|
| 고추탄저병 | 117 | 100.00% | 99.15% | 99.15% |
| 고추흰가루병 | 112 | 100.00% | 100.00% | 100.00% |
| 무검은무늬병 | 76 | 90.79% | 93.42% | 100.00% |
| 무노균병 | 24 | 79.17% | 70.83% | 62.50% |
| 배추검은썩음병 | 110 | 98.18% | 99.09% | 98.18% |
| 배추노균병 | 37 | 100.00% | 100.00% | 100.00% |
| 고추정상 | 1,110 | 99.91% | 100.00% | 99.73% |
| 무정상 | 1,301 | 99.77% | 99.92% | 100.00% |

### 4.3 학습 전 평가와 에폭별 변화

같은 시작 가중치라도 입력 크기에 따라 학습 전 결과가 달랐다. 256의 학습 전 정확도·Macro F1은 99.4349%·0.960803이고, 384는 99.1646%·약 0.942142였다. 각 입력 크기에서 독립적으로 평가한 epoch 0과 학습 후 결과를 구분하였다. [S8]

| 추가 학습 에폭 | 256 Macro F1 | 384 Macro F1 |
|---|---:|---:|
| 0 학습 전 | 0.9608 | 0.9421 |
| 1 | 0.9575 | 0.9600 |
| 2 | 0.9508 | 0.9437 |
| 3 | 0.9541 | 0.9542 |
| 4 | 0.9624 | 0.9405 |
| 5 | 0.9551 | 0.9518 |

에폭 1~5 값은 로그의 소수 넷째 자리 표시값이고 학습 전 값은 최종 비교 문서에서 가져왔다. 256 모델은 4에폭, 384 모델은 1에폭에서 가장 높은 Macro F1을 기록했으며 이후 학습에서 이 최고값을 넘지 못했다. 마지막 에폭을 자동으로 최종 모델로 선택하지 않은 이유이다.

384 모델은 자신의 384 입력 학습 전 상태에 비해서는 Macro F1이 약 0.942142에서 0.960005로 상승하였다. 그러나 기존 256 기준 모델과 비교하면 여전히 낮고, 무노균병 재현율도 낮았다. **384 입력에서의 추가 학습 효과와 입력 크기 384의 상대적 우위는 별개의 판단이다.**

### 4.4 동일한 마지막 5에폭 비교

최고 모델의 선택 에폭 차이를 보완하기 위해, 동일한 학습 기간인 마지막 5에폭의 혼동행렬도 재계산하였다. [S8]

| 모델 입력 | 정답 / 4,070장 | 정확도 | Macro F1 | 무노균병 재현율 |
|---|---:|---:|---:|---:|
| 256 | 4,050 | 99.5086% | 0.955091 | 70.83% |
| 384 | 4,052 | 99.5577% | 0.951798 | 62.50% |

마지막 에폭에서는 384가 정답 2장과 정확도 약 0.0491%p에서 앞섰지만, Macro F1은 256보다 약 0.003293 낮았다. 무노균병 정답도 256은 17장, 384는 15장으로 목표 질병의 개선은 확인되지 않았다. 최고 모델과 마지막 에폭 비교 모두에서 전체 정확도만으로 입력 크기를 결정하기 어렵다는 결과를 얻었다.

## 5. 무노균병 개선 목표의 달성 여부

### 5.1 정밀도와 재현율의 변화

| 모델 | 무노균병 정밀도 | 무노균병 재현율 | 무노균병 F1 |
|---|---:|---:|---:|
| 기존 기준 모델 | 76.00% | 79.17% | 77.55% |
| 256 미세조정 | 85.00% | 70.83% | 77.27% |
| 384 미세조정 | 100.00% | 62.50% | 76.92% |

기존 모델은 무노균병 24장 중 19장을 맞혔고, 256 모델은 17장, 384 모델은 15장을 맞혔다. 기존 대비 재현율은 각각 **8.33%p, 16.67%p 하락**하였다. 검증 표본이 24장이므로 한 장 차이가 약 4.17%p를 만든다. 이는 지표가 민감한 이유이지 오분류의 원인을 확정하는 근거는 아니다.

384 모델의 무노균병 정밀도는 100%이지만, 실제 무노균병 9장을 다른 병해로 분류했다. 무노균병으로 예측한 사진의 정확성은 높아진 반면, 실제 무노균병을 찾아내는 비율은 낮아진 것이다. 정밀도만으로 개선을 판단하지 않았으며 F1도 기존 77.55%에서 76.92%로 낮아졌다.

### 5.2 두 무 병해 사이의 혼동

| 실제 클래스 → 예측 클래스 | 기존 | 256 | 384 |
|---|---:|---:|---:|
| 무노균병 → 무검은무늬병 | 3 | 6 | 9 |
| 무노균병 → 무정상 | 0 | 1 | 0 |
| 무노균병 → 배추정상 | 2 | 0 | 0 |
| 무검은무늬병 → 무노균병 | 6 | 3 | 0 |

무노균병을 무검은무늬병으로 분류한 수가 3장 → 6장 → 9장으로 늘었다. 반대 방향의 혼동은 6장 → 3장 → 0장으로 줄었다. 이번 저장 결과에서는 무검은무늬병을 맞히는 비율이 높아지면서 무노균병을 해당 클래스로 분류하는 오류가 증가하였다.

무검은무늬병 정밀도도 기존 95.83%에서 256 모델 92.21%, 384 모델 89.41%로 낮아졌다. 두 병해의 혼동이 한 방향으로 집중된 결과이며, 해상도 증가가 병징 구분을 전반적으로 개선했다는 결론은 얻지 못했다.

### 5.3 모델 선택 판단

검증 Macro F1만을 기준으로 고르면 256 미세조정 모델이 이번 비교에서 우세하다. 그러나 이번 개선의 주요 목적은 무노균병을 더 잘 찾아내는 것이었고, 그 목표는 두 후보 모두 충족하지 못했다. **256 모델은 전체 지표가 개선된 후보로 보존하되 서비스 교체는 보류하고, 384 모델은 우선 채택하지 않는 방향을 권고한다.**

추가 검토에서는 전체 Macro F1과 무노균병 정밀도·재현율을 함께 판단해야 한다. 새 모델들의 이미지별 예측 목록은 이번 자료에 없으므로, 어느 사진이 새롭게 맞거나 틀렸는지까지 확정하지 않았다. 집계만으로 개별 사진의 변화나 통계적 유의성을 주장하지 않는다.

## 6. 선행 분석과 이번 결과의 관계

### 6.1 학습 크롭 제거 실험

이번 미세조정에 앞서, 입력 256을 유지하고 학습의 RandomResizedCrop을 전체 Resize로 바꾸는 실험을 각각 20에폭 수행하였다. 기존과 크롭 제거의 검증 정확도는 모두 99.4349%였고, Macro F1은 0.960803에서 0.959030으로 낮아졌다. 무노균병 재현율은 두 모델 모두 19/24장인 79.17%로 동일하였다. [S2]

이는 해당 크롭 변경만으로 재현율 개선을 확인하지 못했다는 결과다. 크롭이 오류 원인이 아니라는 결론까지 내리지 않았으며, 회전 등 다른 증강에 따른 잘림 가능성도 남아 있었다. 크롭 제거 모델과 기존 모델을 비교한 공통 무노균병 오류 4장은 별도 검토 자료로 정리되어 있다. 이 4장이 이번 256·384 모델에서도 공통 오류라고 확인한 것은 아니다. [S6]

### 6.2 학습 데이터의 촬영 조건 검토

초기 70장은 특정 작업자의 무노균병 학습 부분집합이었다. 나머지 157장을 포함해 학습 227장 전체의 외관을 검토한 결과, “큰 국소 자국이 잘 드러나지 않는 녹색 앞면” 조건에 부합하는 후보는 3장이었고, 판단이 갈린 2장을 포함하면 5장이었다. 전체의 약 1.3~2.2%에 해당한다. [S7]

초기 70장은 두 검토 결과를 대조했지만 추가 157장은 주 검토와 후보·일부 표본의 교차 확인이었다. 이 범위는 알려진 이견을 반영한 탐색적 집계이고 신뢰구간이나 병해 전문가의 확정 진단이 아니다. 후보 사진은 모두 기존 학습 데이터에 포함되어 있어 신규 데이터 확보로 계산하지 않았다. 드문 촬영 조건이 낮은 재현율의 직접 원인이라는 인과관계도 아직 확인되지 않았다.

## 7. 후속 개선 계획과 결론

후속 작업에서는 다음 순서로 증거를 보완한다.

1. 확보한 실행 로그·최종 비교 문서·모델 파일을 함께 보존하고, 필요하면 동일한 검증 데이터로 모델을 다시 추론하여 저장 지표를 재현한다. 에폭별 손실과 클래스별 지표를 더 자세히 살필 때는 원본 학습 이력도 대조한다.
2. 기존·256·384 모델의 이미지별 예측을 대조하여 무노균병 오류가 어디서 증가했는지 확인한다. 원본 라벨과 병징 판독 가능성을 검토하고 전문가 판단이 가능하면 이견을 기록한다.
3. 학습 단계별 무노균병 지표를 확인한 뒤 모델 선택 기준과 학습 변경을 검토한다. 이미 적용된 균형 샘플링을 고려하며, 에폭·해상도 증가나 특정 손실함수의 효과를 미리 단정하지 않는다.
4. 추가 데이터가 어려우면 기존 모델과 검증 분할을 보존하고 근거가 있는 변경을 한 번에 하나씩 비교한다. 검증 사진을 학습에 넣거나 낮은 성능을 감추기 위해 제외하지 않는다.
5. 최종 모델 선택과 현장 적용 전에는 독립 평가 자료의 확보 가능성, 모바일 촬영 조건 및 대상 장치의 추론 시간·메모리를 확인한다.

**이번 실험에서는 256 미세조정의 전체 검증 지표 개선을 확인했으나, 무노균병 재현율 개선 목표는 달성하지 못했다.** 384 입력의 우위도 확인되지 않았다. 단일 검증 분할을 반복 분석한 결과이므로 성능 향상의 일반화는 별도 평가가 필요하며, 현재 결과를 근거로 무노균병 개선 성공이나 현장 성능 확보를 주장하지 않는다.
