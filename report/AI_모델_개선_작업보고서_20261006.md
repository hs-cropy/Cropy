# AI 모델 개선 작업 보고서

**팀명:** 크래파스

## 금주 예정작업

- 기존 모델의 무노균병 오분류 분석을 바탕으로 추가 데이터 확보 없이 적용할 수 있는 개선 방법을 검토한다.
- 동일한 기존 최고 모델에서 입력 크기 256과 384로 각각 미세조정을 수행하고, 입력 크기에 따른 성능 차이를 비교한다.
- 전체 정확도와 Macro F1뿐 아니라 무노균병 재현율·정밀도 및 무검은무늬병과의 혼동을 확인한다.
- 학습 로그와 저장 모델을 대조하여 결과를 정리하고 후속 개선 방향을 결정한다.

## 금주 수행결과

### 1. 주요 수행 내용 및 팀원 개인별 수행 업무

**김헌영 — 모델 실험 구성, 학습 결과 검증 및 분석**

- **선행 분석 결과 검토:** 무노균병 학습 데이터 227장의 촬영 조건 검토와 크롭 제거 실험 결과를 개선 실험의 근거로 활용하였다. 앞선 크롭 제거 실험에서는 무노균병 재현율이 79.17%로 유지되어 해당 변경만으로는 개선을 확인하지 못했다.
- **입력 크기별 미세조정:** 기존 ResNet50 최고 모델의 동일한 가중치에서 256×256과 384×384 입력으로 각각 5에폭 추가 학습하였다. 학습률 0.00001, 배치 크기 16, 시드 42와 클래스 균형 샘플링 등 나머지 설정은 동일하게 유지하였다.
- **학습 완료 및 모델 선택 확인:** Google Drive의 학습 로그와 최종 비교 문서를 통해 두 실험 모두 5/5에폭 완료를 확인하였다. 검증 Macro F1 기준 최고 모델은 256의 추가 학습 4에폭, 384의 추가 학습 1에폭이었다.
- **결과 정합성 검증:** 로컬 저장 모델과 Drive 비교 문서의 설정·혼동행렬을 대조하고, 혼동행렬에서 성능 지표를 재계산하였다. 최고 모델 비교와 동일한 마지막 5에폭 비교를 구분하여 분석하였다.
- **개선 효과 평가:** 검증 이미지 4,070장을 기준으로 기존 모델과 두 후보의 전체 성능 및 무노균병 성능을 비교하였다.

| 비교 항목 | 기존 모델 | 256 미세조정 | 384 미세조정 |
|---|---:|---:|---:|
| 검증 정확도 | 99.4349% | **99.5823%** | 99.5577% |
| 검증 Macro F1 | 0.960803 | **0.962436** | 0.960005 |
| 전체 오분류 | 23장 | **17장** | 18장 |
| 무노균병 정답 / 표본 | **19 / 24장** | 17 / 24장 | 15 / 24장 |
| 무노균병 재현율 | **79.17%** | 70.83% | 62.50% |
| 무노균병 → 무검은무늬병 오분류 | 3장 | 6장 | 9장 |

표는 각 실행의 최고 모델 기준이다. 256 모델은 기존보다 전체 정답 수가 6장 늘고 Macro F1도 상승했지만, 무노균병 정답 수는 2장 줄었다. 384 모델 역시 무노균병 재현율 개선을 확인하지 못했다. 따라서 **전체 검증 지표의 일부 개선은 확인했으나, 무노균병 재현율 개선 목표는 달성하지 못했다.**

### 2. 주요 문제점

- **전체 성능과 목표 질병 성능의 차이:** 전체 정확도가 높아져도 무노균병 재현율은 떨어졌다. 전체 지표만으로 모델 교체 여부를 결정하기 어렵다.
- **무 질병 간 혼동 지속:** 무노균병을 무검은무늬병으로 분류한 수가 기존 3장에서 256은 6장, 384는 9장으로 늘어 두 질병을 구분하는 문제가 남아 있다.
- **검증 표본과 추가 데이터의 제약:** 무노균병 검증 표본은 24장으로 한 장 차이가 재현율 약 4.17%p에 해당한다. 추가 데이터 확보가 어려워 기존 데이터 안에서 개선 방법을 검토해야 한다.
- **오류 원인 확인의 한계:** 이번 자료에는 새 모델의 이미지별 예측 목록이 없어 어떤 사진에서 오류가 증가했는지는 추가 확인이 필요하다. 현재 결과는 단일 검증 분할의 결과이며 독립 테스트 성능을 의미하지 않는다.

### 3. 해결 방법 및 대응

- **완료한 대응:** 입력 크기를 제외한 설정을 맞추고 같은 시작 가중치와 검증 분할을 사용하여 비교하였다. 학습 완료 기록과 저장 모델의 지표를 대조해 결과의 일관성을 확인하였다.
- **평가 방식 보완:** 정확도·Macro F1과 함께 무노균병 정밀도·재현율 및 혼동 방향을 분석하였다. 최고 모델과 마지막 에폭을 별도로 비교하여 학습을 오래 하거나 입력 크기를 늘리는 것만으로 개선되었다고 판단하지 않았다.
- **모델 선택 제안:** 전체 지표가 가장 높은 256 모델을 개선 후보로 보존하되, 무노균병 성능 저하를 고려해 서비스 모델의 즉시 교체는 보류하는 방향을 제안하였다. 384 모델의 우위는 확인되지 않았다.
- **미해결 사항의 후속 조치:** 기존·256·384 모델의 이미지별 예측을 확보해 오류 증가 사례를 확인하고, 그 결과를 근거로 다음 실험을 설계하기로 정리하였다.

## 다음주 예정작업

1. 같은 검증 이미지에 대한 기존·256·384 모델의 예측 클래스와 확률을 저장하여 이미지별 비교 목록을 작성한다.
2. 무노균병과 무검은무늬병의 오분류 이미지를 대조하고, 병징의 가시성·촬영 조건·원본 라벨을 검토한다.
3. 전체 Macro F1과 무노균병 재현율을 함께 고려하는 모델 선택 기준을 정리하고, 오류 분석으로 근거가 확인된 변경을 한 번에 하나씩 비교한다.
4. 기존 학습·검증 분할을 유지하면서 후속 실험 결과를 기록하고, 목표 질병 성능 개선 여부를 확인한 뒤 모델 적용 여부를 판단한다.
