# Cropy Figma 기반 백엔드 보완 작업 보고서

작성일: 2026-10-08. 사용자의 백엔드 검토 후 작업 승인과 **두 오프라인 실행 방식 모두 지원** 선택에 따라 구현했다. Figma 원본·다른 섹션은 수정하지 않았다. 작업 시작 전에 존재하던 문서·학습·데이터 관련 변경도 유지했다.

## 구현 내용

| 항목 | 반영 내용 |
|---|---|
| 진단 이력 | 작물·등급 필터, 페이지네이션, 전체/작물/필터 건수, 정상·병해/등급/재촬영 요약 |
| 과거 결과 보존 | 신규·재촬영 병해 설명·원인·예방·관리 행동·농약 조회·판단 정책 스냅샷과 버전. 기존 스냅샷 없는 이력은 현재 참고값으로 표시 |
| 판단 기준 | 작물 불일치·혼동·낮은 신뢰도 이유 구분. 기본 0.5 기준을 서버 설정으로 관리. 재촬영 후에도 혼동 여부 재평가 |
| 저장 복구 | DB 저장 실패 결과를 서버 전용 디스크 초안에 기본 24시간 보관. 결과를 먼저 표시하고 재추론 없는 다시 저장 제공. 만료·변경 충돌 구분 |
| 재시도·동시성 | 요청 키와 사진/작물 지문, 성공 응답과 기록의 원자적 저장. 동일 요청 재사용, 다른 본문 충돌 차단, 동시 재촬영 승자 응답 재사용 |
| 오류·준비 상태 | 기존 detail 유지, 오류 code/retryable/request_id 추가. 사진·모델·기록·DB·복구 보관 실패 구분. capabilities API |
| 프론트 연동 | 필터·빈 이력 구분·재조회·저장 복구·관리 안내·현재 농약 조회. 같은 재촬영 사진으로 재시도, 분석 중 입력 변경 방지, 요청 수신 중단 처리 |
| Orange Pi 로컬 실행 | 기존 서버 추론·SQLite 방식 유지. 외부 인터넷 없이 로컬 네트워크에서 실행하는 배포 절차 문서화 |
| 브라우저 자체 실행 | ONNX 모델 변환·검증, 같은 사이트의 WASM 런타임, 페이지 캐시, IndexedDB 모델·사진·결과 저장, 기기 내 진단·두 사진 융합·이력·내보내기·삭제 |
| 기기 기록 동기화 | 명시적으로 선택한 기록 전송, 버전·확률·사진 검증, 당시 안내 저장, browser 출처 표기, 응답 유실 후 동일 본문 재전송 |
| 배포·보관 | frontend Docker public 포함, backend 동일 묶음 마운트, 기존 manifest 아카이브 유지. 만료 전 복구 사진을 업로드 정리에서 보존 |

관리 행동은 기존 수동 시드의 예방 안내에서 구성했으며 새로운 현장 검증이나 전문가 승인 완료를 뜻하지 않는다. 등급도 기존 병해 카탈로그 분류를 사용하며 사진별 병반 면적·중증도 분석을 새로 구현한 것이 아니다.

## 검증

- 전체 백엔드: **200 passed, 1 skipped**. 심볼릭 링크 생성이 허용되지 않는 호스트 테스트를 건너뛰었다.
- 프론트엔드 프로덕션 빌드: 성공. 타입 검사·정적 페이지 생성 포함.
- 오프라인 판단 단위 테스트: **3 passed**.
- 실제 Chrome 통합 검증: 모델 준비 → 실제 WASM 추론 → 네트워크 차단 → 새로고침·이력·새 진단 → 실제 서버 commit 후 응답 유실 → 재전송과 중복 없는 이력 저장 통과. 페이지 JS 오류 없음.
- ONNX 모델: 약 **94MB**, 동일 텐서 3개에서 PyTorch 대비 최대 logit 차이 **1.4007091522216797e-6**. 변환 허용 오차 통과.
- 저장 실패·복구 만료·동시 재촬영·미저장 사진 보존·두 사진 요청 제한·묶음 버전 불변성을 회귀 테스트로 확인했다.
- 자동 검증은 테스트 전용 DB·업로드 경로를 사용했다. 실제 운영 DB를 변경하지 않았다.

## 실제 배포 전에 남은 확인

휴대폰 Chrome/Safari의 메모리·추론 속도·저장소 유지, Orange Pi 실제 장치 배포와 처리 속도, 실제 농장 사진 전처리·정확도는 이번 PC 검증에서 확인하지 않았다. Docker Compose 설정은 검사했지만 운영 Docker 이미지 빌드·장치 실행을 완료했다고 주장하지 않는다.

브라우저 자체 오프라인 준비는 HTTPS 또는 개발용 localhost에서 사용한다. 기기의 한국어 로컬 음성이 있으면 결과 읽기를 제공하지만 음성 명령/STT·LLM 상담은 이번 구현에 포함하지 않았다. 농약 실동기화는 실행하지 않았고 오프라인 묶음에도 농약 사용 조건을 포함하지 않았다. S1/S2 시안의 신뢰도나 처리 시간은 실제 출력으로 대체하며 숫자를 강제로 맞추지 않는다.
