## 1. 3주차 — 기존 데이터 점검 및 평가용 데이터셋 재설계

### 1.1 주요 수행 내용 및 개인별 수행 업무

김헌영은 기존 ResNet50 분류 모델의 추가 학습 결과를 분석하고, 성능 개선을 가로막는 데이터 문제를 점검하였다. 일반 샘플링과 역빈도 균형 샘플링을 비교했으며, 원본·축소 이미지 평가와 데이터 중복 검사를 진행하였다. 이후 AI Hub 설명서와 라벨을 확인하여 새로운 분할 후보를 마련하였다.

| 작업 | 수행 내용 | 산출물·결과 |
|---|---|---|
| 기존 모델 분석 | 클래스별 성능·혼동행렬·오분류 확인 | 검증 637장 중 613장 정답, 96.23% |
| 추가 학습 비교 | 동일 시작 모델에서 일반·균형 샘플링 각각 12 epoch | 기존 모델을 넘는 결과를 확보하지 못해 유지 |
| 이미지 전처리 비교 | 동일 모델·224 입력으로 원본과 축소본 평가 | 원본 94.66%, 축소본 96.23% |
| 분할 중복 점검 | 이미지 해시 및 원본 대조 | train–val 2쌍, train–test 4쌍 중복 발견 |
| 라벨 연결 | 제공 라벨 아카이브의 JSON 91,041개 분석 | 현재 이미지 4,246장 모두 고유 라벨 연결 |
| 분할 후보 설계 | 수집 작업자 기준으로 데이터 분리 | train 2,739 / val 785 / test 722 |

### 1.2 데이터셋 구성과 품질 점검

분류 대상은 고추탄저병, 고추흰가루병, 무검은무늬병, 무노균병, 배추검은썩음병, 배추노균병과 고추·무·배추 정상 클래스이다.

기존 실험은 학습 2,972장, 검증 637장, 테스트 637장으로 구성된 번들을 사용하였다. 중복 점검 결과, 평가용 이미지 일부가 학습 이미지와 동일한 것으로 확인되어 기존 검증 정확도를 완전히 독립된 일반화 성능으로 해석하기 어려웠다.

9월 21일에는 제공된 TAR 18개 안의 라벨 자료를 점검하여 현재 이미지 4,246장을 연결하고, 날짜 불일치 2건을 기록하였다. 설명서를 통해 파일명의 날짜 앞 코드는 수집 작업자 ID임을 확인하였다. 작업자와 날짜의 조합을 개체 ID로 단정하지 않았다.

새 분할 후보는 모든 클래스를 포함하면서 작업자와 동일 이미지 해시가 서로 다른 분할에 중복되지 않도록 구성하였다. 3주차에는 분할 후보와 검증 목록을 마련했으며, 해당 시점의 후보 작성 자체를 새 모델 학습 완료로 계산하지 않았다.

### 1.3 성능 개선 실험 결과

| 실험 | 주요 조건 | 결과 | 판단 |
|---|---|---|---|
| 기존 기준 모델 | ResNet50, RGB 224×224, 기존 검증 637장 | 96.23% | 비교 기준 유지 |
| 일반 샘플링 추가 학습 | seed 42, batch 32, 12 epoch, lr 2e-5 | 학습 중 최고 약 96.2% | 기준 초과 없음 |
| 균형 샘플링 추가 학습 | 동일 조건, 역빈도 샘플링 적용 | 학습 중 최고 약 96.1% | 기준 초과 없음 |
| 원본 이미지 평가 | 동일 검증 이미지·체크포인트·224 전처리 | 603/637, 94.66% | 원본 사용만으로 개선되지 않음 |
| 축소 이미지 평가 | 기존 번들의 축소·JPEG 재인코딩 이미지 | 613/637, 96.23% | 기존 Colab 예측과 전 표본 일치 |

추가 학습의 최고 수치는 로그 반올림 값이다. 저장 조건인 시작 모델의 전체 검증 정확도 초과를 충족하지 않아 새 모델을 채택하지 않았다. 기존 검증 오류 24건 중 무 두 병해 간 혼동이 13건으로, 전체 오류의 약 54.17%를 차지하였다.

### 1.4 주요 문제점

1. 학습·평가 데이터 중복으로 기존 지표의 독립성이 불충분하였다.
2. 무검은무늬병과 무노균병의 혼동이 집중되어 전체 정확도만으로 취약점을 설명하기 어려웠다.
3. 확보한 정상 이미지 1,500장이 모두 공식 Validation 출처여서 공식 분할대로만 재배치하면 정상 학습 데이터가 없어지는 제약이 있었다.
4. 추가 학습이나 원본 이미지 사용만으로 개선을 보장할 수 없었다. 촬영 조건·병징 가시성·라벨 문제의 영향을 구분할 필요가 있었다.

### 1.5 해결 방법 및 주차 결과

- 해시와 라벨을 이용해 중복·출처 문제를 확인하고, 작업자 기준 분할 후보를 생성하였다.
- 기존 자료와 서비스 모델을 보존하고 실험별 분할·전처리·학습 조건을 기록하였다.
- 성능이 개선되지 않은 추가 학습 모델을 채택하지 않았다.
- 원본·라벨 확인을 우선하며 모델의 오분류만으로 정답 라벨을 변경하지 않는 원칙을 정하였다.

3주차의 핵심 성과는 정확도 향상 자체보다 **기존 평가의 한계를 발견하고 새 비교 실험을 위한 데이터 분할 근거를 확보한 것**이다.

## 2. 4주차 — 작업자 분리 기준선 분석 및 입력 해상도 비교

### 2.1 주요 수행 내용 및 개인별 수행 업무

김헌영은 새로운 작업자 분할을 적용한 ResNet50 224 학습 결과를 기준선으로 분석하고, 동일 분할의 256 입력 실험과 비교하였다. 결과 파일의 무결성, 분할 manifest, 표본별 정답·예측, 혼동행렬, 체크포인트 메타데이터를 대조하였다.

추가로 백엔드의 모델 출력 검증과 진단 결과 표시를 개선하고, 팀원의 카메라 구현을 현재 작업본과 결합하여 촬영부터 진단·이력 조회까지 동작을 확인하였다. 카메라 구현 자체는 팀원의 작업이며 본인의 수행 범위는 검토와 통합 검증이다.

### 2.2 비교 조건

| 항목 | 조건 |
|---|---|
| 모델 | ImageNet V2 사전학습 ResNet50, 9클래스 전체 파인튜닝 |
| 데이터 | 동일한 작업자 분리 manifest |
| 실제 학습 번들 분할 | 학습 2,728 / 검증 785 / 테스트 722, 총 4,235장 |
| 공통 설정 | seed 42, batch 32, 20 epoch |
| 비교 변수 | 입력 크기 224와 256 |
| 평가 범위 | 검증 785장; 최종 test 미평가 |

과거 96.23%와 이번 기준선 91.85%는 데이터 분할·전처리·학습 조건이 다르므로 직접적인 성능 하락으로 해석하지 않는다. 성능 개선 여부는 같은 조건의 224·256 실험 사이에서 비교한다.

3주차의 4,246장 분할 후보에서 학습 내 동일 바이트 중복 11장을 제거한 4,235장 번들을 실제 학습에 사용하였다. 후보 수량과 실제 학습 수량을 구분하며, 근거는 `ml/pack_group_baseline.py`와 `output/colab/group_baseline_20260921/bundle_info.json`이다.

### 2.3 성능 개선 결과

|---|---:|---:|---:|
| 최고 모델 epoch | 20 | 19 | — |
| 검증 정확도 | 91.85% | 92.48% | 약 +0.64%p |
| 정답 수 | 721/785 | 726/785 | +5장 |
| Macro F1 | 0.9035 | 0.9099 | +0.0064 |
| 전체 오분류 | 64건 | 59건 | -5건 |
| 병해를 정상으로 분류 | 29건 | 22건 | -7건 |

| 배추노균병을 배추정상으로 분류 | 14건 | 11건 | -3건 |

### 2.4 주요 문제점

1. 전체 정확도는 개선됐지만 무검은무늬병 재현율과 무 병해 간 구분은 악화되었다.
2. 단일 seed 실험이므로 256 입력의 안정적인 우위를 확정할 수 없다.
3. 작업자 분리는 개체·농장 독립성을 보장하지 않는다. 특히 무노균병 검증 표본은 작업자 1명의 49장으로 구성되어 있다.
4. 최종 test와 실환경 평가는 수행하지 않아 현장 적용 적합성을 확정할 수 없다.
5. 카메라 미리보기와 저장 이미지의 범위가 달라 사용자가 맞춘 구도와 모델에 전달되는 구도가 달라질 수 있음을 확인하였다. 정확도 영향은 아직 측정하지 않았다.

### 2.5 해결 방법 및 적용 결과

- 전체 정확도와 함께 클래스별 재현율, 병해→정상 오류, 표본별 개선·악화를 비교하였다.
- 256 모델은 후보로 보존하고 서비스 모델 교체나 임계값 변경은 진행하지 않았다.
- 새로운 오류 12건과 무 병해 혼동 31건을 원본·라벨 검토 대상으로 정리하였다.
- 백엔드에서 비정상 모델 출력과 미등록 클래스를 차단하고 모델·전처리 버전을 진단 이력에 기록하도록 개선하였다.
- 낮은 분류 점수와 선택·예측 작물 불일치를 화면에서 안내하도록 연동하였다.
- 가상 카메라로 촬영→실제 모델 추론→결과 표시→이력 저장·상세 조회를 확인하였다. 이는 연결 검증이며 합성 영상의 분류 결과를 모델 정확도 평가에 사용하지 않았다.
