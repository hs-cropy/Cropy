## 클라우드 사용목적

본 프로젝트는 고추·무·배추의 병해를 진단하는 AI 모델을 개발하고, 이를 모바일 웹과 현장 진단 단말기에 적용하는 것을 목표로 한다. 현재 개발 환경은 CPU 기반으로, 전체 이미지 데이터를 이용한 반복 학습과 성능 비교 실험을 수행하는 데 시간이 소요된다. 이에 Google Colab 유료 서비스의 클라우드 GPU 자원을 활용하여 모델 학습 및 검증을 수행하고자 한다.

사용 데이터는 이미지 손상 검사와 중복 제거, 정답 라벨 연결을 완료한 학습 이미지 32,513장과 검증 이미지 4,070장으로 구성된다. 업로드용 데이터는 전체 36,583장을 유지하면서 긴 변을 최대 512픽셀로 축소한 사본이며, 원본 이미지는 별도로 보존한다.

ResNet50 모델을 기반으로 클래스 간 데이터 수 차이를 고려한 균형 샘플링과 학습 이미지 증강을 적용한다. 입력 크기 256픽셀, 20회 반복 학습을 초기 설정으로 사용하고, 배정된 GPU 자원과 이용 가능 시간 내에서 학습 결과 및 설정별 성능을 검토한다. 검증 정확도, Macro F1, 질병별 재현율을 통해 모델의 성능을 평가하며, 검증 Macro F1이 가장 높은 모델을 저장한다. GPU 종류나 특정 학습 시간의 확보를 전제로 하지 않는다.

마음AI 산학협력 교육 자료와 제공 예정 환경을 활용하여 음성 인식(STT), 대화 응답(LLM), 음성 합성(TTS)을 연계하는 현장 음성 안내 기능도 개발한다. 사용자의 질문을 인식하고, CNN 진단 결과와 검증된 병해·농약 정보를 쉬운 한국어로 설명한 뒤 음성으로 안내하는 흐름을 목표로 한다. 기존 계획에 따라 제공 VAD/STT/TTS 예제와 RKLLM 환경을 우선 검증하며, 마음AI SUDA의 적용 여부는 SDK 제공 조건과 대상 보드 지원 여부를 확인하여 결정한다.

클라우드 GPU는 농업 도메인 대화 데이터의 학습 실험과 LLM 기본 모델·미세조정 모델의 비교 평가에 활용한다. 기본 모델에서 반복되는 응답 오류가 확인될 경우 LoRA/QLoRA 방식의 소규모 미세조정을 수행하고, 진단 설명의 정확성, 제공 정보에 대한 일치도, 정보 부족 시 확인 질문 여부를 평가한다. STT는 작물명·병명 인식 오류를, TTS는 한국어 발음·숫자·단위 전달의 명료성을 검증한다. STT·TTS의 추가 학습은 제공 모델의 학습 지원 여부와 학습용 음성 데이터 확보 여부를 확인한 뒤 필요한 범위에서 진행한다. 모델을 처음부터 학습하거나 마음AI 제공 모델 전체를 자유롭게 재학습할 수 있다고 가정하지 않는다.

CNN 학습을 우선 수행하고, 이후 잔여 예산과 GPU 이용 가능 시간 내에서 LLM 및 음성 관련 소규모 실험을 순차적으로 수행한다. 음성·대화 모델의 구체적인 모델명과 버전은 제공 환경 확인 후 확정하며, 현재 STT·TTS·LLM 학습 완료 실적으로 기재하지 않는다.

학습 노트북, 실행 설정, 학습 기록, 모델 파일 및 성능 평가 결과를 산출물로 남긴다. 음성·대화 분야에서는 검수한 대화 데이터, 기본 모델과 미세조정 모델의 비교 결과, STT 인식 오류 및 TTS 낭독 점검 결과를 실험 수행 범위에 맞춰 추가한다. Google Drive는 데이터 전달과 학습 결과·체크포인트 보관에 활용하며, 이번 신청의 유료 구매 대상은 Colab 서비스로 한정한다. 마음AI API·SDK 사용료는 현재 구매 내역에 포함하지 않는다. CNN 학습 중단 시 마지막으로 완료한 회차부터 재개할 수 있도록 구성하였다. 학습한 모델은 후속 검증과 최적화를 거쳐 Orange Pi 기반 현장 진단 시스템에 적용할 계획이다.

클라우드는 모델 개발·학습에 활용하며 현장 진단은 로컬·온디바이스 방식으로 구현한다. 별도 최종 테스트는 아직 수행하지 않았으므로 검증 지표를 최종 독립 평가 성능으로 간주하지 않는다.

### 원본 양식의 작성 공간이 좁을 때 사용할 요약문

Google Colab 유료 서비스의 클라우드 GPU를 활용하여 농작물 병해 진단 CNN 학습과 마음AI 산학협력 교육·제공 환경 기반의 음성·대화 기능 개발을 수행하고자 한다. 중복 제거와 라벨 검증을 완료한 학습 32,513장·검증 4,070장으로 ResNet50을 학습하고, 정확도·Macro F1·질병별 재현율을 평가한다. 또한 농업 도메인 대화 데이터를 활용한 LLM 소규모 미세조정과 STT·TTS 연계 검증을 진행한다. STT·TTS 추가 학습은 제공 모델의 지원 범위와 음성 데이터 확보 여부에 따라 결정한다. 예산 범위 내에서 CNN 학습을 우선하고 음성·대화 실험을 순차 수행하며, 모델·학습 로그·평가 보고서를 남겨 Orange Pi 기반 현장 진단 및 음성 안내 기능에 활용할 계획이다.
