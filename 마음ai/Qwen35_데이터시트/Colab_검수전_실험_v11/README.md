# 사람 검수 전 Qwen3.5 Colab 실험

작성자: 김헌영  
일자: 2026-10-08

사람 검수 없이 학습 경로를 먼저 점검하려는 요청을 반영한 실험용 버전입니다. 기존 사람 검수표와 승인 조건이 있는 노트북은 유지합니다. 데이터의 approved 상태를 변경하지 않습니다.

## 파일 업로드

Drive에 다음 구조로 파일을 둡니다. 기존 cropy_qwen_v11 폴더가 있다면 하위 실험 폴더만 추가하면 됩니다.

```text
MyDrive/cropy_qwen_v11/
  Cropy_Qwen35_기능별400_검수대기_v11.xlsx
  Colab_검수전_실험_v11/
    Cropy_Qwen35_검수전_실험_v11.ipynb
    cropy_qwen_pilot.py
```

노트북은 Colab의 파일 메뉴에서 업로드하여 열 수도 있습니다. helper 파일은 위 Drive 폴더에 있어야 합니다. 사람 검수표나 대조용 정답 CSV는 이 실험에 필요하지 않습니다.

## 실행

1. Colab에서 실험 노트북을 열고 런타임 유형을 GPU로 선택합니다.
2. 처음부터 셀을 순서대로 실행하고 Drive 접근을 허용합니다. 기본 모델은 Qwen/Qwen3.5-2B이며 RUN_MODEL_STEPS=True입니다.
3. 원본 해시·함수·인자·토큰·AI 검토 상태·학습/검증 분할 검사를 통과하면 모델을 로드합니다.
4. 토큰 인코딩·정답 구간 loss 마스킹·새 토큰 gradient 검사 후 20 step 학습하고 검증·저장·재로딩 대조를 진행합니다.
5. Drive의 unreviewed_experiment_v11_실행시각 폴더에서 environment.json, selected_cases.json, train_metrics.json, eval_metrics.json, eval_cases.json, reload_check.json을 확인합니다. 실행마다 새 폴더를 사용합니다.

패키지 설치 후 Colab이 런타임 재시작을 안내하면 재시작하고 처음부터 다시 실행합니다. 중단한 실행을 자동으로 재개하는 노트북은 아닙니다.

## 기본 수량과 해석

전체 2,800개 초안 중 기존 split을 유지하며 각 기능에서 학습 16개·검증 4개를 고정 seed로 뽑습니다. 실제 사용 수량은 학습 112개·검증 28개이며 MAX_STEPS=20입니다. 이 설정은 학습 흐름 확인용이고 충분한 학습이나 신뢰할 만한 최종 성능 평가를 의미하지 않습니다.

모델이 규칙대로 토큰을 출력하는지, loss가 유한한지, 추가 토큰 가중치가 학습되는지, 저장 후 재로딩 결과가 같은지를 먼저 확인하세요. 초기 완전 일치율이 낮아도 20 step만으로 학습 가능성을 단정하지 않습니다. 정확도는 미검수 초안의 정답을 기준으로 한 값이며 사람 검수된 평가 성능과 구분합니다.

동작 확인 후 원본 전체 초안 실험을 원하면 MAX_TRAIN_PER_FUNCTION=320, MAX_EVAL_PER_FUNCTION=80으로 바꾸고 MAX_STEPS를 별도로 정합니다. 모든 데이터를 충분히 학습하는 step 수는 실제 길이·GPU·loss·검증 추이를 확인한 후 결정합니다. 현재 기본 노트북은 2,800개 전체를 학습하지 않습니다.

## 로컬에서 확인한 범위

원본을 변경하지 않고 사람 승인 없이 데이터 로딩, 해시 불일치 차단, 잘못된 출력 및 분할 교차 차단, 기존 사람 승인 노트북의 승인 0개 차단, 노트북 코드 구문을 확인했습니다. Colab GPU에서 모델 다운로드·역전파·학습·저장·재로딩을 실제 실행한 것은 아닙니다.

실제 함수 실행·TTS·보드용 양자화는 별도 작업입니다. 기존 승인 검수용 노트북의 사용 안내는 ../Colab_파일럿_v11/README.md를 참고하세요.
