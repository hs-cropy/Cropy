# 농약 정보 기능 400개 확장

작성자 김헌영 · 2026년 10월 6일

기존 v2의 농약 싱글턴 23개를 보존하고 합성 발화 377개를 추가했다. 농약 기능만 학습 320개 검증 80개로 분할했다. 다른 기능은 기존 파일럿이며 전체 싱글턴은 497개 학습 396개 검증 101개다. 멀티턴 40개는 보류 상태다.

신규 원문 가족은 138개다. 정상 발화 138개 합성 STT 변형 128개 합성 사투리 변형 111개로 구성했다. 동일 가족의 변형은 한 분할에만 배치했으며 검증용 원문은 별도로 작성했다. 400개는 변형을 포함한 대화 수이며 서로 다른 의도 400종이나 실제 음성 400건을 뜻하지 않는다.

모델 입력에는 사용자 발화와 근거 JSON만 사용한다. 정답 유형이 포함된 검수용 그룹 ID와 분할 정보는 근거 JSON에서 제거했다. 원문 가족과 합성 출처는 외부 검수 칸에 보존했다. 정답 토큰 반환 상태 TTS 예시 및 검수 메타데이터를 모델 입력으로 넘기지 않는다.

신규 컨텍스트 138개는 가상 제품을 사용하는 합성 자료다. 백엔드의 active_ingredient와 safety.phi_days 및 safety.reentry_hours 필드 구조를 적용했다. 공식 등록 정보와 사용량 희석량 및 안전 사용 수치는 생성하지 않았다. 신규 희석 사용 수확 제한 재진입 성분 효과 비교 혼용 요청은 정보 부족 상태다. 실제 사용 조건을 성공적으로 제공하는 사례는 공식 자료를 확보한 뒤 보완해야 한다.

자동 검증에서 입력 문장부호와 동일 발화 및 그룹 분할 충돌은 0개였다. 전체 581개 행의 함수 인자 토큰 종료 컨텍스트와 TTS 키 연결을 확인했고 저장된 수식 오류는 0개였다. 확장한 행의 승인 상태 변경에 따라 수량 집계가 갱신되는 것도 확인했다. v2 원본과 기존 데이터 및 토큰 매핑은 보존했다. Excel 파일을 다시 읽어 저장 결과를 점검했으며 실제 Excel 앱 동작을 직접 실행한 검증은 아니다.

모든 데이터는 draft다. 실제 사람 검수와 승인 실제 토큰 ID 등록 기능 handler 및 TTS 실행 모델 학습과 평가는 하지 않았다. 특히 STT 의미 보존 사투리의 자연스러움 모호한 제품 지칭의 확인 기능 전환은 사람 검수가 필요하다. 농약 400개 외의 기능은 아직 400개로 확장하지 않았다.
