## 추가 및 보존한 내용

- 신규 원문 가족 780개, 발화 2,303개. 정중한 발화·구어체·합성 STT를 포함했다. 장면 문구와 질문 조합을 사용했으므로 독립 의도 780종이나 실제 녹음으로 설명하지 않는다.
- 신규 합성 STT 743개. 발음식 표기나 띄어쓰기만 보수적으로 변형했고 부정어·숫자의 의미를 임의로 바꾸지 않았다. 실제 STT 녹음·정답 전사 자료는 없다.
- 신규 근거 컨텍스트 780개. 병해 설명·일반 원인·예방 항목은 저장소 seed에서 가져왔다. 모델 점수·버전명·식별자는 합성이다. 공식 검증 자료나 실제 API 스냅샷으로 표시하지 않았다.
- 신규 TTS 조합 10개를 추가하고 참고 답변을 각 근거에 연결했다. handler·TTS 실행은 아직 구현·검증 전이다.
- 기존 농약 불합격 13개·보류 23개와 AI 내용검수 기록을 보존했다. 이번 구축으로 그 결함을 해결했다고 표시하지 않았다.
- 기존 예시 및 멀티턴을 보존했으며 2,800개 싱글턴 집계에서 제외했다.

## 자동 검증 결과

- 모든 기능의 400개·320대80 집계 확인. 검증 초안 560개와 평가 계획 연결 확인.
- 동일 입력 중복 0건. 원문 그룹·시드·공백 제거 원문 발화의 분할 교차 0건.
- 기능·인자 enum·토큰 문자열·종료 토큰·TTS 키·근거 ID 연결 검사 통과.
- 입력 및 의도 발화의 문장부호·불필요한 기호 위반 0건.
- 확장 범위의 표·조회 수식·집계 수식·입력 제한을 점검했다. 저장된 셀의 수식 오류 0건.
- v4 원본과 기존 근거·대화·검수·평가·STT·토큰 값을 보존했다. 필요한 범위 확장과 표지 문구·관련 TTS 근거만 변경했다.

## 검수 및 학습 상태

싱글턴 상태: draft 2400개, reviewed 387개, rejected 13개, approved 0개.

수량은 초안 수량이며 승인 완료 수량이 아니다. 새로 추가한 행의 검수자·검수일은 비워 두었다. 다음 작업은 신규 6개 기능의 전체 의미 검수, 농약 결함과 보류 해결, 원문 가족 단위 분할 재확인이다. 사용자 발화와 필요한 컨텍스트만 모델 입력에 넣고 정답·원문·그룹·split·검수 메모를 입력에서 제외해야 한다.

Colab 본학습 전 tokenizer의 실제 토큰 ID, 종료 동작, 데이터 exporter와 채팅 템플릿, handler·TTS 연결을 소량 시험으로 확인해야 한다. 이번 작업에서 모델을 학습하거나 평가 점수를 생성하지 않았다.

관리 priority, 현장 피해량·식용 안전·상태 변화는 현재 근거가 부족한 사례를 포함한다. 제공된 관리 목록의 순서를 효과 순위로 바꾸거나 모델 점수를 현장 수치로 바꾸지 않는다. 지원 범위·모호함을 기능 수량 때문에 조회 기능으로 이동시키지 않는다.
